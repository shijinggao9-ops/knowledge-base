
| 模块 | 核心问题 | 关键输出 |
|:-----|:---------|:---------|
| **市场分析** | 市场有多大？在增长吗？ | 市场规模、增速、趋势、驱动力 |
| **商业模式** | 怎么赚钱？凭什么赚钱？ | 收入模型、成本结构、利润逻辑 |
| **竞争力评估** | 护城河有多深？能守住吗？ | 竞争壁垒、差异化、KSF匹配度 |
| **风险识别** | 什么事会毁掉这个投资？ | 风险清单、概率/影响评估 |

### 2.2 商业尽调的提问清单

#### 模块一：市场分析

| 问题 | 具体拆解 |
|:-----|:---------|
| 市场空间有多大？ | TAM/SAM/SOM分别是多少？ |
| 市场在增长还是萎缩？ | 增长率是多少？驱动力是什么？ |
| 市场结构是什么？ | CR3/CR5是多少？集中度趋势？ |
| 市场处在哪个阶段？ | 萌芽期、成长期、成熟期、衰退期？ |
| 未来3-5年的关键变化？ | 技术、政策、消费习惯的变化方向？ |

#### 模块二：商业模式

| 问题 | 具体拆解 |
|:-----|:---------|
| 提供什么产品/服务？ | 解决了什么用户痛点？ |
| 收入来源是什么？ | 卖什么？怎么收费？定价策略？ |
| 成本结构是什么？ | 固定成本 vs 可变成本？规模效应？ |
| 利润模型成立吗？ | 毛利率？净利率？单位经济模型？ |
| 现金流状况如何？ | 经营现金流为正吗？需要多少营运资金？ |

#### 模块三：竞争力评估

| 问题 | 具体拆解 |
|:-----|:---------|
| 市场地位是什么？ | 市场份额？排名？趋势？ |
| 护城河来自哪里？ | 品牌？技术？网络效应？规模？ |
| 差异化是什么？ | 用户为什么选你而不是竞品？ |
| KSF匹配度如何？ | 行业KSF vs 公司能力的匹配度？ |
| 竞争对手在做什么？ | 竞品的战略意图和动向？ |

#### 模块四：风险识别

| 问题 | 具体拆解 |
|:-----|:---------|
| 最大的3个风险是什么？ | 概率？影响程度？ |
| 风险之间有无关联？ | 一个风险触发另一个？ |
| 有什么应对措施？ | 怎么降低概率？怎么减少影响？ |
| 最坏情况是什么？ | 如果所有风险同时发生？ |
| 风险调整后的回报？ | 风险是否被充分定价？ |


## 三、商业模式验证

商业模式验证是商业尽调的核心——它回答“这家公司赚钱的逻辑是否成立”。

### 3.1 单元经济分析

单元经济（Unit Economics）是验证商业模式是否成立的核心工具——它把复杂的公司财务拆解到“一个单元”来看是否赚钱。

| 概念 | 定义 | 公式 |
|:-----|:-----|:-----|
| **CAC**（用户获取成本）| 获取一个付费用户所需成本 | 总销售营销费用 ÷ 新增付费用户 |
| **LTV**（用户生命周期价值）| 一个用户整个生命周期贡献的收入 | ARPU × 平均生命周期 |
| **单位毛利**（Contribution Margin）| 每个用户贡献的毛利 | ARPU - 单位可变成本 |
| **回本周期**（Payback Period）| 收回CAC所需时间 | CAC ÷ 月均贡献毛利 |

**判断标准**：

| 指标 | 健康标准 | 危险信号 |
|:-----|:---------|:---------|
| LTV/CAC | > 3 | < 2 |
| 回本周期 | < 12个月 | > 24个月 |
| 单位毛利为正 | 是 | 否 |

**示例——SaaS公司单元经济**：

| 参数 | 数值 | 判断 |
|:-----|:----:|:-----|
| CAC | $300 | — |
| 月均ARPU | $50 | — |
| 月流失率 | 3% | — |
| 平均生命周期 | 33个月 | — |
| LTV | $50 × 33 = $1,650 | — |
| LTV/CAC | 1,650/300 = 5.5 | ✅ 优秀 |
| 回本周期 | 300 / (50×40%) ≈ 15个月 | ✅ 可接受 |

### 3.2 收入质量分析

验证收入的“真实质量”是尽调的关键环节。

| 维度 | 高质量收入的特征 | 低质量收入的特征 |
|:-----|:-----------------|:-----------------|
| 重复性 | 订阅/经常性收入占比高 | 一次性收入为主 |
| 可预测性 | 收入可预测 | 收入波动大、靠大单 |
| 客户集中度 | 客户分散、无依赖 | 前5大客户占比高 |
| 增长来源 | 内生增长（留存+复购）| 靠新客户获取驱动 |
| 定价权 | 有提价能力 | 只能被动跟随市场 |

### 3.3 增长逻辑验证

增长逻辑验证是判断“未来故事是否可信”——“故事讲得好”不等于“逻辑能走通”，增长逻辑验证的核心是确认“假设有依据、路径可追踪、数字能算清”。

| 维度 | 要问的问题 | 验证方法 |
|:-----|:-----------|:---------|
| 增长来源 | 增长来自新客户还是老客户增值？ | 分析NDR和新客户MRR的贡献比例 |
| 增长路径 | 增长有清晰的路径吗？ | 看获客渠道的ROI和天花板 |
| 增长门槛 | 增长需要什么前置条件？ | 看团队、资金、时间三者的匹配度 |
| 增长节奏 | 增长曲线合理吗？ | 看历史数据和行业对标 |
| 增长天花板 | 距离天花板还有多远？ | 看市场渗透率和潜在可触达用户 |

**增长路径验证清单**：

- [ ] 获客渠道：现有渠道的ROI是多少？天花板在哪？
- [ ] 留存效果：NDR是否>100%？流失率是否在下降？
- [ ] 扩张计划：新市场/新产品的进入逻辑是什么？
- [ ] 执行能力：团队有无大规模扩张的历史记录？


## 四、风险识别

### 4.1 风险分类框架

| 风险类型 | 来源 | 典型表现 |
|:---------|:-----|:---------|
| **市场风险** | 行业变化 | 市场萎缩、竞争加剧、替代品出现 |
| **商业风险** | 商业模式脆弱 | 单元经济不成立、客户集中度高、定价权弱 |
| **运营风险** | 执行能力不足 | 供应链断裂、人才流失、质量失控 |
| **财务风险** | 资金问题 | 现金流断裂、应收账款过高、债务过高 |
| **技术风险** | 技术变革 | 技术落后、被新技术替代 |
| **监管风险** | 政策变化 | 监管收紧、合规成本上升 |
| **团队风险** | 人的问题 | 创始人冲突、核心团队流失、文化不匹配 |
| **退出风险** | 退出路径 | IPO窗口关闭、并购市场低迷 |

### 4.2 风险地图

用风险地图对风险进行优先级排序：

高影响  
│  
│ 【重点关注】 【紧急处理】  
│ 影响大、概率中 影响大、概率高  
│  
│ 【定期监控】 【快速应对】  
│ 影响小、概率中 影响中、概率高  
│  
└─────────────────────────────────→  
低概率 高概率
### 4.3 风险应对策略

| 策略 | 做法 | 适用场景 |
|:-----|:-----|:---------|
| **规避** | 不投/退出 | 风险不可控、影响毁灭性 |
| **转移** | 保险、对赌条款 | 风险可量化、可转移 |
| **降低** | 投资后主动管理 | 风险可控、有应对空间 |
| **接受** | 保留风险、降低估值 | 风险可控、在可接受范围内 |
| **对冲** | 组合投资 | 风险难以单点消除 |


## 二、商业场景还原

### 场景1：SaaS公司投资尽调

**情境**：你正在评估一家SaaS公司，年收入$5M，连续3年增长100%。

**尽调要点**：

**市场分析**：
- TAM 50亿，年增速15%
- 目标客群：中小企业（SAM=5亿）
- 目前渗透率约2%

**商业模式验证**：
- CAC=$400，LTV=$2,400，LTV/CAC=6.0 ✅
- NDR=115%（老客户收入持续增长）✅
- 客户集中度：前10大客户占收入15%（分散）✅

**竞争力评估**：
- 差异化：垂直行业定制化解决方案
- 护城河：行业经验积累 + 数据网络效应

**风险识别**：
- ⚠️ 核心团队最近流失2名销售（运营风险）
- ⚠️ 竞争对手刚完成1亿美元融资（竞争风险）

**结论**：商业模式健康，增长逻辑成立，需关注团队稳定性。

### 场景2：消费品牌投资尽调

**情境**：你正在评估一个DTC护肤品牌，年收入$10M，增长80%。

**尽调要点**：

**商业模式验证**：
- 渠道结构：线上占比85%，依赖抖音和小红书
- 复购率：35%（行业平均40%）⚠️
- CAC：$45，LTV：$120，LTV/CAC=2.7（略低于健康线3.0）

**竞争力评估**：
- 差异化：成分党的品牌定位
- 护城河：品牌认知度有限，用户忠诚度中等

**风险识别**：
- 🔴 渠道高度集中（抖音占70%）——平台政策变化风险
- 🔴 复购率低于行业平均
- 🟡 竞品（3-5个）在做同样的事情

**结论**：品牌增长快，但渠道集中度高，需关注复购率优化和渠道多元化。


## 三、常见误区

| 误区 | 真相 |
|:-----|:-----|
| “尽调就是找问题” | ❌ 尽调的目标是“全面评估”——既找问题也找亮点，最终判断“值不值” |
| “增长快=值得投” | ❌ 增长快要看质量——靠补贴换来的增长、靠压货换来的增长，不可持续 |
| “创始人靠谱=项目靠谱” | ⚠️ 创始人很重要，但不能只看创始人——要看“创始人和业务是否匹配”以及“团队整体是否具备大规模扩张能力” |
| “估值高=好公司” | ❌ 估值是“价格”，好公司是“价值”——再好的公司，价格太贵也不值得投 |
| “尽调做完就能决定投不投” | ❌ 尽调是“输入”，投资决策还要看估值、条款、portfolio组合、投后管理能力 |
