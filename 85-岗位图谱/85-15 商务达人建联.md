## 一、岗位本质认知

达人建联不是"发私信求人"，而是**用数据筛选匹配达人 + 用内容价值说服合作 + 用流程管理提升效率**的系统工程。

你的核心身份是：**品牌与达人之间的「价值翻译官」**——把品牌的卖点翻译成达人愿意接的内容，把达人的影响力翻译成品牌看得懂的ROI。

---

## 二、核心能力一：达人筛选能力

### 2.1 筛选逻辑总框架

达人筛选的本质是**「用最低成本找到最高匹配度」**。不要追求"最好的达人"，要追求"最合适的达人"。

行业共识：粉丝量只是最表层指标，账号内容调性、互动质量、观众结构、历史合作习惯往往比粉丝数更能决定合作值不值得推进。

### 2.2 定量分析维度（数据层）

#### 第一层：基础健康度指标

| 指标 | 计算方式/判断标准 | 为什么重要 | 工具/数据来源 |
|------|------------------|-----------|-------------|
| **粉互比** | 粉丝数 / (点赞+收藏+评论总量) | 衡量粉丝活跃度，<1:1.5 警惕，1:10 以内较好 | 千瓜/蝉妈妈/新榜 |
| **互动率** | (点赞+评论+分享) / 播放量 × 100% | 行业黄金线：>5% 为优质，<2% 需警惕 | 平台后台/第三方工具 |
| **粉丝增长趋势** | 近30天新增粉丝 / 总粉丝 | 负增长=近期不活跃或掉粉，正增长且稳定=内容能力可靠 | 千瓜/蝉妈妈 |
| **水粉占比** | 异常粉丝 / 总粉丝 | >20% 需警惕，可能刷量 | 第三方检测工具 |
| **视频播放稳定性** | 近10条视频播放量标准差 | 波动过大说明内容能力不稳定，不要只看一条爆款 | 手动统计/工具 |
| **带货转化率** | 成交订单数 / 视频播放量 × 100% | 行业参考：>1.5% 为可合作基准 | 平台电商数据 |
| **GMV/场均GMV** | 近30天带货总额 / 直播场次 | 衡量实际带货能力，比粉丝量更真实 | 蝉妈妈/考古加 |
| **完播率** | 完整观看人数 / 总播放人数 | 短视频>15%，直播>30% 为较好水平 | 平台创作者后台 |

#### 第二层：商业价值指标

| 指标 | 计算方式 | 判断标准 |
|------|---------|---------|
| **CPM（千次曝光成本）** | 合作报价 / (预估播放量/1000) | 对比行业均值，判断性价比 |
| **CPE（单次互动成本）** | 合作报价 / 预估互动量 | 越低越好，但需结合互动质量 |
| **ROI（投入产出比）** | 带货GMV / 合作成本 | >3 为健康，>5 为优秀 |
| **粉丝画像重合度** | 达人粉丝画像 vs 品牌目标用户画像 | >40% 为黄金匹配线 |

> **行业黄金公式**：粉丝画像重合度>40% + 内容互动率>5% + 带货转化率>1.5% = 值得推进的达人

#### 第三层：风险排除指标

| 红旗信号 | 具体表现 | 处理方式 |
|---------|---------|---------|
| 刷量嫌疑 | 粉丝量高但互动率极低、评论区全是表情/无意义评论 | 直接排除 |
| 内容违规史 | 近期被平台处罚、限流、封号记录 | 直接排除 |
| 竞品绑定过深 | 近期密集合作直接竞品，且为独家/深度绑定 | 评估是否还能合作 |
| 报价虚高 | CPM 显著高于同量级达人均值 | 砍价或降级为备选 |
| 履约率低 | 历史合作中「接单但不发布」比例高 | 直接排除 |

### 2.3 定性分析维度（内容层）

定量数据告诉你「能不能合作」，定性判断告诉你「值不值得合作」。

#### 维度1：内容垂直度
- **判断方法**：翻看达人近30条内容，统计垂类内容占比
- **标准**：垂类内容占比>70% 为垂直账号，<50% 为泛娱乐账号
- **策略**：垂类账号转化率高但破圈能力弱；泛娱乐账号曝光大但转化低。根据品牌阶段选择。

#### 维度2：内容调性匹配度
- **判断方法**：提取达人内容的关键词、视觉风格、语言风格
- **标准**：与品牌调性的「情感温度」是否一致
  - 高端轻奢品牌 → 避开口播式、夸张式达人
  - 平价快消品牌 → 避开口吻过于「精英感」的达人
  - 功能性产品 → 优先找「测评型」「教程型」达人

#### 维度3：人设真实性与信任度
- **判断方法**：
  - 评论区是否出现真实用户的「求助式提问」（如"这个适合油皮吗"）
  - 达人是否回复评论区、回复质量如何
  - 是否有「翻车」历史或争议事件
- **标准**：真实互动比例高、无重大负面、人设稳定的达人更值得长期合作

#### 维度4：内容生产能力
- **判断方法**：
  - 视频制作质量（画质、剪辑、节奏）
  - 文案能力（标题吸引力、卖点提炼）
  - 更新频率（周更>3条为佳，断更超过2周需警惕）
- **标准**：内容生产能力强的达人，合作时你只需要给Brief，不需要给脚本

#### 维度5：商业合作成熟度
- **判断方法**：
  - 是否有过品牌合作经验（翻看历史合作视频）
  - 合作视频的质量 vs 日常视频的质量（是否敷衍）
  - 是否有自己的商务团队或经纪人（影响沟通效率）
- **标准**：有成熟商务流程的达人合作效率高，但报价也更高；首次接商务的达人可能配合度好但流程混乱

### 2.4 达人分层策略

#### 2.4.1达人分类

| 达人定位 | KOL                            | KOC                         | KOP                                  | KOS                               |
| ---- | ------------------------------ | --------------------------- | ------------------------------------ | --------------------------------- |
| 含义   | 意见领袖                           | 意见消费者                       | 专业行业意见领袖                             | 关键意见销售                            |

不要只盯着头部。行业实践表明，**中腰部达人+素人矩阵**的ROI往往高于单一头部。

| 层级 | 粉丝量 | 角色定位 | 合作策略 | 预算占比建议 |
|------|--------|---------|---------|------------|
| **头部** | 100万+ | 破圈曝光、品牌背书 | 1-2个/季度，用于大促或新品首发 | 40% |
| **中腰部** | 10-100万 | 场景渗透、精准转化 | 批量合作，按品类/场景分组 | 35% |
| **素人/纳米** | 1-10万 | 口碑沉淀、真实感 | 铺量合作，低成本高覆盖 | 20% |
| **KOC/员工** | <1万 | 私域裂变、UGC补充 | 零成本或置换合作 | 5% |

### 2.5 达人筛选实操SOP

```
Step 1：明确合作目标
  → 种草曝光？直接带货？素材回收？市场测试？
  → 目标不同，筛选权重完全不同

Step 2：建立初筛池（工具批量筛选）
  → 用蝉妈妈/千瓜/新榜，按品类+粉丝量+互动率筛选
  → 初筛标准：互动率>3%，近30天有更新，无违规记录
  → 目标：建立200+人的初筛池

Step 3：人工精筛（逐个翻看主页）
  → 看近10条视频的内容质量、评论区氛围
  → 看粉丝画像（年龄/性别/地域）与品牌匹配度
  → 看历史合作视频的质量和效果
  → 目标：从200人精筛到50人

Step 4：分级打标签
  → A级（立即推进）：数据健康+调性匹配+有合作意愿
  → B级（备选观察）：某一项有短板但可培养
  → C级（排除）：有明显红旗信号

Step 5：建立达人档案
  → 字段：达人ID、平台、粉丝量、互动率、带货转化率、
         内容调性、粉丝画像、历史合作品牌、报价、
         联系方式、跟进状态、备注
```

## 三、核心能力二：内容策划能力

### 3.1 内容策划的本质

内容策划不是"写脚本给达人念"，而是**「把产品卖点翻译成达人语言」**。

核心原则：
- **达人熟悉自己的粉丝**，品牌熟悉自己的产品
- 你的工作是搭建桥梁，而不是代替达人创作
- 给方向、给卖点、给参考，但不给逐字稿

### 3.2 内容方向策划

根据合作目标，内容方向分为四大类：

| 内容方向 | 适用场景 | 核心要素 | 达人类型偏好 |
|---------|---------|---------|------------|
| **种草测评** | 新品上市、功能型产品 | 真实体验、前后对比、痛点解决 | 测评型、教程型达人 |
| **场景植入** | 生活方式类、情感类品牌 | 自然融入生活场景、不硬广 | Vlog型、生活方式达人 |
| **直播带货** | 大促、清库存、冲销量 | 实时互动、限时优惠、紧迫感 | 直播型、带货型达人 |
| **创意挑战** | 破圈、年轻化品牌 | 参与感强、易模仿、自带传播属性 | 泛娱乐、剧情型达人 |

### 3.3 Brief（创意简报）撰写规范

一份好的Brief能让达人快速理解「你要什么」，同时保留达人的创作空间。

#### Brief 标准结构

```markdown
# 【品牌名】×【达人名】合作Brief

## 一、项目背景
- 品牌简介（1-2句话）
- 本次合作目标（曝光/带货/素材/测试）
- 产品核心卖点（不超过3个）

## 二、内容要求
- 内容形式：短视频/直播/图文
- 必提卖点：（按优先级排序，最多3个）
- 必现元素：（如产品包装、使用场景、价格信息）
- 禁忌事项：（如不能提竞品、不能夸大功效）

## 三、风格参考
- 提供2-3个参考视频链接（可以是该达人自己的优质内容，也可以是竞品案例）
- 说明「参考的是什么」：节奏？结构？话术？氛围？

## 四、发布要求
- 发布时间：（建议给出时间段，如"周末晚8-10点"）
- 发布平台：（抖音/小红书/B站/视频号）
- 话题标签：（提供3-5个建议标签）
- @账号：（是否需要@品牌官方号）

## 五、数据预期与结算
- 保底播放量/互动量：（如有）
- 结算方式：CPS/CPM/一口价
- 结款周期

## 六、样品与物流
- 样品清单
- 寄送地址
- 预计到货时间
```

### 3.4 内容审核要点

达人提交内容后，审核不是「挑刺」，而是「确保不翻车」。

| 审核维度 | 检查清单 | 处理方式 |
|---------|---------|---------|
| **合规性** | 是否涉及虚假宣传、夸大功效、医疗宣称 | 必须修改，否则法律风险 |
| **品牌一致性** | Logo、产品名、卖点是否准确 | 小错提醒修改，大错打回重做 |
| **内容质量** | 画质、音质、剪辑节奏是否达标 | 可接受范围内不过度干预 |
| **自然度** | 是否像硬广？达人自己的风格是否保留？ | 过于硬广建议软化，但不能强制改风格 |
| **评论区引导** | 是否设置了购买链接/优惠券/搜索关键词 | 检查链接有效性 |

> **关键原则**：品牌过度干预创意会导致达人内容真实性下降。消费者更愿意相信真实、客观的内容。给达人空间，把控底线即可。

### 3.5 内容复用策略

一次达人合作，内容价值不止于单条视频。

| 复用方式 | 操作 | 价值 |
|---------|------|------|
| **素材回收** | 要求达人提供无字幕原片、高清产品特写 | 用于品牌官方号、信息流广告 |
| **切片分发** | 将长视频切分为3-5个15秒片段 | 二次传播，覆盖不同场景 |
| **评论区运营** | 品牌官方号在评论区互动、置顶购买引导 | 提升转化率 |
| **投流放大** | 对优质内容投放Dou+/信息流 | 用付费流量撬动自然流量 |
| **长期绑定** | 与表现好的达人签季度/年度合作 | 降低单次合作成本，建立信任背书 |

## 四、核心能力三：数据分析能力

### 4.1 数据分析的本质

达人建联的数据分析不是「事后统计」，而是**「全流程用数据指导决策」**。

从建联到复盘的完整数据链路：

```
建联阶段 → 寄样阶段 → 内容发布 → 效果追踪 → 复盘优化
   ↓           ↓           ↓           ↓           ↓
回复率      寄样率      发布率      播放量      ROI
通过率      物流时效    内容质量    互动量       CPM
           签收率      发布时间    转化率       复购率
                                    客单价       长尾流量
```

### 4.2 全流程核心指标

#### 阶段一：建联效率指标

| 指标 | 计算方式 | 健康基准 | 优化方向 |
|------|---------|---------|---------|
| **回复率** | 回复你的达人数 / 总建联达人数 | >20% 为健康 | 优化首条话术、筛选更匹配的达人 |
| **通过率** | 同意合作的达人数 / 回复的达人数 | >30% 为健康 | 优化报价策略、提升Brief吸引力 |
| **平均跟进次数** | 总跟进次数 / 成功合作数 | <3次为佳 | 优化首条信息质量，减少无效跟进 |

#### 阶段二：执行效率指标

| 指标 | 计算方式 | 健康基准 | 优化方向 |
|------|---------|---------|---------|
| **寄样率** | 实际寄出样品的达人数 / 同意合作的达人数 | >80% | 优化样品申请流程 |
| **签收率** | 确认签收的达人数 / 寄出样品的达人数 | >90% | 选择靠谱物流、及时同步单号 |
| **发布率** | 实际发布内容的达人数 / 签收样品的达人数 | >70% | 加强签收后跟进、提供拍摄支持 |
| **平均执行周期** | 从建联到发布的平均天数 | <14天 | 优化流程节点、设置Deadline提醒 |

#### 阶段三：内容效果指标

| 指标 | 计算方式 | 健康基准 | 优化方向 |
|------|---------|---------|---------|
| **播放量** | 视频/直播总播放 | 对比达人历史均值 | 内容质量、发布时间、投流 |
| **互动率** | (点赞+评论+分享) / 播放量 | >5% | 内容吸引力、话题设计 |
| **转化率** | 成交订单数 / 播放量 | >1.5% | 产品匹配度、价格、购买链路 |
| **GMV** | 总销售额 | 对比预期目标 | 达人带货能力、产品竞争力 |
| **ROI** | GMV / 合作总成本 | >3 | 达人选择、内容质量、投流效率 |

#### 阶段四：长期价值指标

| 指标 | 计算方式 | 意义 |
|------|---------|------|
| **长尾流量占比** | 发布后7-30天的流量 / 总流量 | 小红书>30%为优秀，说明内容有搜索价值 |
| **内容复用价值** | 素材二次使用的曝光量 / 原视频曝光量 | 衡量一次合作的综合价值 |
| **达人复购率** | 二次合作的达人数 / 总合作达人数 | >30% 说明达人池质量高 |
| **品牌搜索指数变化** | 合作前后品牌词搜索量变化 | 衡量种草效果 |

## 五、建联话术与谈判技巧

### 5.1 首条消息结构（决定回复率的关键）

```
【首条消息公式】

1. 赞美/认同（1句）→ 证明你不是群发
   "看了你最近那期《油皮底妆测评》，评论区好多人在问链接，说明粉丝购买力很强"

2. 价值说明（1-2句）→ 告诉达人「合作对他有什么好处」
   "我们是XX品牌，主打平价油皮底妆，和你的粉丝画像非常匹配。这次合作除了基础佣金，还提供投流支持"

3. 行动召唤（1句）→ 降低回复门槛
   "方便的话可以加个微信，我把产品资料和Brief发你看看？"

4. 联系方式 → 给达人选择权
   "我的微信：XXX，或者你留微信我加你也行"
```

**禁忌：**
- ❌ 群发通用模板（达人一眼看出）
- ❌ 只讲品牌多厉害，不讲对达人有什么好处
- ❌ 一上来就谈钱（先建立信任）
- ❌ 消息过长（手机端超过3屏基本不看完）

### 5.2 谈判常见场景应对

| 场景 | 达人说法 | 你的应对 |
|------|---------|---------|
| **嫌报价低** | "我别的品牌都给XX" | "理解，我们的预算确实有限。不过除了基础费用，我们还提供【投流支持/长期合作/独家折扣码分成】，综合收益可能更高。要不我们先试一条，数据好的话下条按你的标准来？" |
| **没档期** | "最近排满了" | "没问题，你的内容质量值得等。我们先加个微信，有合适的产品我提前给你留档期？" |
| **要求先寄样看看** | "先寄样品我试试" | "完全理解，产品体验是合作的基础。我这就安排寄样，同时把Brief也发你，你可以先看看内容方向是否感兴趣" |
| **对比竞品** | "XX品牌给的条件更好" | "每个品牌的合作模式不一样。我们的优势是【具体优势，如投流/长期绑定/产品差异化】，而且我们看重的是长期合作，不是一锤子买卖" |
| **内容自主权** | "我不接受改脚本" | "完全尊重你的创作风格。我们的Brief只提供卖点方向和参考，具体内容你自由发挥。我们只把控【合规底线/品牌信息准确性】" |

### 5.3 跟进节奏

| 节点 | 动作 | 话术要点 |
|------|------|---------|
| **Day 0** | 首次建联 | 见5.1首条消息公式 |
| **Day 3** | 未回复，首次跟进 | "Hi，上次发的合作邀请不知道你看到了吗？我们的产品和你最近的内容方向很匹配，方便聊聊吗？" |
| **Day 7** | 仍未回复，二次跟进 | "理解你消息比较多。这次合作除了基础费用，还有【额外价值】，如果你感兴趣可以加我微信详聊，不打扰~" |
| **Day 14** | 最后跟进 | "这次合作窗口期快到了，如果你感兴趣请本周内回复，过期我就释放名额给其他达人了（温和施压）" |
| **Day 14+** | 标记为B级，3个月后重新触达 | 不要死磕，保持关系即可 |
