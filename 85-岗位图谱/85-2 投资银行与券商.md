# 85-2 投资银行与券商

**定位**：投资银行（Investment Banking）是资本市场的核心中介，为企业融资（IPO、定增、发债）、并购重组、资产重组等提供顾问与执行服务。券商研究所则提供卖方研究服务，为买方机构（基金、保险、资管）提供投资决策支持。这是商科中"财务门槛最高、工作强度最大、起薪最具竞争力"的路径之一。
**适合人群画像**：对数字极度敏感、能承受高强度工作（每周80-100小时）、追求短期高回报、对资本市场有强烈兴趣、细致到偏执。
&gt;
**行业格局**：外资投行（Goldman Sachs、MS、JPM、Citi等）→ 头部券商（中信、中金、中信建投、华泰）→ 颈部券商（国君、海通、招商、申万）→ 腰部及以下券商 → 精品投行（FA：华兴、易凯、泰合等）

## 一、核心能力矩阵

| 能力维度      | 权重  | 说明                                                          |
| :-------- | :-: | :---------------------------------------------------------- |
| **财务分析**  | ★★★ | 核心门槛。三张表勾稽关系、DCF、可比公司/先例交易、LBO建模，决定Technical面试生死            |
| **抗压与细致** | ★★★ | 体力+心力双重考验。Pitch Book改到第20版、招股书核对到标点符号、通宵是常态                 |
| **行业认知**  | ★★★ | 对覆盖行业（如新能源、半导体、消费、医药）的深刻理解，能讲清楚"这个行业怎么赚钱"                   |
| **沟通表达**  | ★★☆ | 对外：路演、客户沟通、谈判；对内：与律师、会计师、监管的多方协调                            |

| **工具技能**  | ★★☆ | Excel（快捷键到肌肉记忆）、PPT（Pitch Book排版）、Wind/Bloomberg/Capital IQ |
| **结构化思维** | ★★☆ | 交易结构设计、尽职调查清单、项目时间线管理                                       |
| **商业洞察**  | ★★☆ | 交易逻辑、估值合理性、市场窗口判断                                           |

## 二、硬门槛与准入条件

| 门槛类型            | 具体要求                                                        |
| :-------------- | :---------------------------------------------------------- |
| **学历背景**        | 外资投行：清北复交+海外Target School（HYPSM等）；头部券商：清北复交人+两财一贸+南大/浙大/武大等 |
| **GPA**         | 3.5+/4.0 或专业前15%，财务相关课程（会计、财管、公司金融）成绩尤其重要                   |
| **实习经历**        | 四大审计/FA/研究所/腰部券商 → 颈部/头部券商 → Summer Intern → Return Offer   |
| **Technical能力** | 三张表、DCF、可比估值、M&A会计、债券基础，能独立完成完整财务模型                         |
| **证书**          | CPA（会计+财管+税法）、CFA一级（非必须但加分）、保代（长期）                          |
| **英语能力**        | 外资投行需流利商务英语；头部券商需能阅读英文招股书、写英文材料                             |
| **行业认知**        | 对1-2个赛道有超越同龄人的理解（如新能源、AI、生物医药、消费）                           |

## 三、面试考察全景图

### 3.1 Fit / Behavioral（行为面试）
**占比**：20-30%（外资投行占比更高，头部券商相对更看重Technical）
**核心问题**：
- Why IBD? Why not consulting/PE?
- Why our firm? Why this group?（TMT组/医疗组/新能源组）
- Tell me about a time when you had to deliver perfect work under extreme deadline.
- Walk me through your resume.（每个数字都可能被追问）
**准备方法**：
- 准备6-8个STAR故事，覆盖：抗压/熬夜、细致/零差错、团队协作、领导力、快速学习
- 针对每家券商的**优势业务**准备Why Firm：
  - 中金："投行贵族"、跨境业务、国际化视野
  - 中信：全牌照、项目体量、行业覆盖广度
  - 中信建投：IPO承销王者、股权融资优势
  - 华泰：科技赋能、国际化（AssetMark）、研究实力

### 3.2 Technical Interview（专业面试）
**占比**：50-60%（头部券商甚至更高）
**核心模块**：

| 模块 | 考察重点 | 典型问题 |
|:-----|:---------|:---------|
| **会计基础** | 三张表勾稽关系、收入确认、折旧方法、商誉、少数股东权益 | "折旧增加10块，三张表怎么变？" |
| **估值建模** | DCF（WACC/Terminal Value/敏感性分析）、可比公司（Trading Comps）、先例交易（Transaction Comps） | "Walk me through a DCF" |
| **M&A会计** | Purchase Price Allocation、Goodwill、Accretion/Dilution分析 | "收购一家公司，EPS是增厚还是稀释？" |
| **债券基础** | 债券定价、YTM、Duration、Convexity、可转债条款 | "为什么可转债对发行人有利？" |
| **市场动态** | 近期IPO、并购重组案例、市场窗口、监管政策 | "最近你看好哪个IPO项目？估值合理吗？" |
| **Excel建模** | 现场搭模型或口述模型结构、三张表联动、循环引用处理 | "现场搭一个LBO模型"（外资/精品投行） |

**Technical进阶考察（面试官真正打分的地方）**：
- **不是背公式，而是理解经济含义**：WACC里为什么用目标资本结构？Terminal Growth Rate为什么不能高于GDP增速？
- **敏感性分析思维**：关键假设变动对估值的影响，能说出"哪些变量对结果影响最大"
- **交易逻辑**：不是算出一个数字，而是能论证"为什么这个估值区间合理"

### 3.3 笔试环节
**常见形式**：
- **行测**：言语理解、数量关系、逻辑推理（券商总部管培常见）
- **专业笔试**：会计分录、财务分析、估值计算、行业研究框架
- **性格测试**：无明显对错，但极端选项需谨慎

## 四、差异化竞争力（如何脱颖而出）

| 竞争力类型 | 具体表现 | 为什么值钱 |
|:-----------|:---------|:-----------|
| **完整项目经历** | 参与过IPO、定增、并购的某一环节，能讲清楚自己在交易中的角色和贡献 | 投行最怕"纸上谈兵"，有项目经验意味着上手快、培训成本低 |
| **特定行业深度** | 对某一赛道（如创新药、半导体、新能源）有产业链级别的认知 | 投行按行业分组，行业专家能更快赢得客户信任 |
| **财务+数据复合** | 不仅懂三张表，还能用SQL/Python处理财务数据、搭建自动化报表 | 投行数字化转型、CDD（Commercial Due Diligence）越来越需要 |
| **法律/监管认知** | 熟悉《证券法》、IPO审核要点、再融资新规、并购重组管理办法 | 投行是"金融+法律"的交叉，懂法规的人能更快发现交易障碍 |
| **多语言能力** | 流利英语（外资/港股/美股IPO刚需）+ 第二外语（如日语/德语对应特定市场） | 跨境并购、海外上市、GDR项目的刚需 |
| **学术深度** | 发表过财务/金融相关论文、对某一估值模型有创新应用 | 适合研究所路径，或投行中偏研究的岗位 |

    ↓
