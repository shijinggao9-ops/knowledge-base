# 85-8 企业战略与战投

**定位**：企业战略与战略投资（Corporate Strategy & Strategic Investment，简称"战投"）是大型企业的"内部智库"和"资本触角"。战略部负责制定公司中长期发展方向、竞争策略、业务组合优化；战投部负责通过并购（M&A）、股权投资、合资合作等方式实现外延增长。这个岗位是"咨询+投行+行业研究"的甲方综合体，离CEO/董事会最近，能直接参与影响公司命运的重大决策。
 **适合人群画像**：对商业全局有强烈掌控欲、享受"从0到1"的战略设计过程、能接受高度不确定性、擅长跨部门推动和向上管理、有咨询/投行/研究背景作为跳板、不排斥大量案头研究和专家访谈。
**行业格局**：
 - **互联网/科技巨头战投**：腾讯投资、阿里战投、字节战投、美团战投、小米战投（最活跃，覆盖TMT、消费、企服、硬科技）
- **产业资本/CVC**：华为哈勃、宁德时代战投、比亚迪战投、药明康德战投（围绕主业产业链布局）
- **国企/央企战略部**：国投、中信集团、华润战略部（偏宏观政策、重组整合、五年规划）
 - **外企战略部**：MBB alumni聚集地，偏市场进入、竞争策略、数字化转型
 - **独角兽/中厂战略部**：偏业务落地，战略部常兼PMO职能，直接推动重点项目

## 一、核心能力矩阵

| 能力维度 | 权重 | 说明 |
|:---------|:----:|:-----|
| **商业洞察** | ★★★ | 核心门槛。对行业趋势、竞争格局、商业模式、技术演进的深度理解，能画出产业链地图、预判未来3-5年变化 |
| **财务分析** | ★★★ | 核心门槛。估值建模（DCF/可比交易）、三张表分析、投资回报测算、协同效应量化。战投岗要求不低于投行 |
| **结构化思维** | ★★★ | 战略部日常输出：行业研究报告、战略规划书、董事会汇报材料。需要极强的逻辑架构和Storyline能力 |
| **沟通与推动** | ★★★ | 对内：向CEO/VP汇报、推动业务部门执行战略；对外：与标的方谈判、与FA/投行/律师协调。没有实权，全靠影响力 |
| **行业认知** | ★★★ | 比咨询更垂直、比投行更深入。互联网战投要求对TMT全赛道有认知；产业资本要求对特定产业链（如新能源/半导体/医药）有专家级理解 |
| **数据分析** | ★★☆ | 行业数据搜集（专家访谈/研报/数据库）、市场规模测算（TAM/SAM/SOM）、竞品数据监控、投资后财务追踪 |
| **工具技能** | ★★☆ | Excel（财务建模）、PPT（战略汇报）、Wind/Capital IQ/PitchBook（数据）、Python/SQL（数据处理，加分项） |
| **项目管理** | ★★☆ | 战略项目从诊断到落地的全周期管理；战投项目从Sourcing到交割到投后管理的全流程把控 |
| **抗压与政治敏感度** | ★★☆ | 战略决策涉及部门利益博弈，需要读懂组织政治；战投项目周期长（6-18个月），不确定性高，需承受高压 |

## 二、硬门槛与准入条件

| 门槛类型 | 具体要求 |
|:---------|:---------|
| **学历背景** | 极高。头部互联网战投和顶级产业资本偏好清北复交+海外Target School（HYPSM/LBS/INSEAD）；外企战略部几乎被MBB alumni垄断 |
| **实习/工作背景** | **这是最大的硬门槛**。理想路径：MBB/ Tier 2咨询 → 投行/FA → 甲方战略/战投；或：头部券商研究所 → 买方研究 → 战投。应届生直接进战投极难，通常需要2-3年乙方经验 |
| **财务功底** | 战投岗要求独立完成完整财务模型（Operating Model/LBO/M&A Model），理解Purchase Price Allocation、Goodwill、Accretion/Dilution |
| **行业深度** | 对1-2个赛道有"专家级"认知：产业链上下游、关键玩家、技术路线、监管政策、估值水平、交易历史 |
| **证书** | CFA（尤其二级/三级）、CPA是加分项，非必须但越来越卷 |
| **英语能力** | 能阅读英文研报、撰写英文Investment Memo、参与跨境谈判。外企战略部要求流利商务英语 |
| **人脉与信息源** | 战投岗需要持续Source项目，与FA、创业者、投资人保持联系。应届生虽不要求，但有行业人脉是巨大加分项 |

## 三、面试考察全景图

### 3.1 Fit / Behavioral（行为面试）
**占比**：20-30%（战投岗Behavioral比重低于咨询，但高于投行）
**核心问题**：
- Why corporate strategy / strategic investment? Why not pure consulting / PE?
- Why our company?（对这家企业的战略方向、投资布局、竞争态势的理解）
- Tell me about a time when you changed someone's mind with data and logic.
- Tell me about a time when you had to make a recommendation with incomplete information.
- Tell me about a time when you navigated a complex organizational landscape to get something done.（政治敏感度）
- 对简历上每个Deal/项目经历深挖：你在其中具体做了什么？估值怎么算的？关键假设是什么？

**准备方法**：
- 准备6-8个STAR故事，覆盖：战略思维、财务分析、谈判推动、组织博弈、快速学习、抗压
- 针对目标公司准备"战略诊断"：
 - 这家公司过去3年做了什么重大战略决策？（如字节跳动退出游戏、阿里拆分）
 - 它的战投/投资部投了哪些公司？逻辑是什么？
 - 它面临的最大战略挑战是什么？如果我是战略部，我会建议什么？

### 3.2 Case / Technical Interview（案例与专业面试）
**占比**：40-50%
**经典题型与考察重点**：

| 题型 | 考察重点 | 高频场景 |
|:-----|:---------|:---------|
| **Market Entry / Expansion** | 市场吸引力、进入模式、资源需求、风险与回报 | "某新能源车企是否应该进入东南亚市场" |
| **M&A / Investment Thesis** | 战略协同、财务估值、整合风险、Deal Structure | "A公司是否应该收购B公司？Synergy怎么算？" |
| **Strategic Options** | 业务组合优化、增长路径选择、优先级排序 | "某传统零售企业面临电商冲击，三条路怎么选？" |
| **Industry Landscape** | 产业链分析、竞争格局、技术趋势、监管影响 | "怎么看AI对在线教育行业的重塑？" |
| **Due Diligence** | 财务DD、商业DD、法律DD、运营DD的关键关注点 | "投资一家SaaS公司，DD重点看什么？" |

**Case进阶考察（面试官真正打分的地方）**：
- **战略高度 vs 落地可行性**：不仅要有Big Picture，还要能落到"具体第一步做什么、谁来做、花多少钱"
- **组织视角**：作为甲方，要考虑"这个战略我们能不能执行"（组织能力、文化匹配、资源约束），而非仅做外部市场分析
- **投资逻辑**：战投岗要求区分"战略投资"（产业协同）和"财务投资"（回报驱动），理解CVC的特殊性（如腾讯投资的"连接器"逻辑）
- **风险识别**：能说出"这个Deal最大的三个风险是什么"，而非只讲Upside

### 3.3 财务建模与估值（Financial Modeling）
**占比**：20-30%（战投岗Technical比重高于咨询，接近投行）
**核心要求**：
- 现场搭或口述一个M&A Model或DCF Model
- 三张表联动（IS/BS/CFS）
- Purchase Price Allocation、Goodwill计算、Pro Forma合并报表
- Synergy量化（Revenue Synergy vs Cost Synergy）
- 敏感性分析（WACC、Terminal Growth、Synergy实现率对IRR的影响）

**常见追问**：
- "如果收购后第一年Revenue下降10%，对IRR的影响？"
- "Goodwill减值测试怎么做？什么情况下会触发？"
- "Earn-out条款怎么设计？对估值有什么影响？"

### 3.4 行业深度面试（Industry Deep Dive）
**占比**：10-20%（这是战投岗区别于咨询/投行的独特环节）
**形式**：面试官是某行业的专家，连续追问产业链细节
**典型问题**：
- "新能源汽车的电池成本曲线未来5年怎么走？"
- "半导体设备行业的'卡脖子'环节具体在哪？国产替代进度如何？"
- "创新药从研发到上市的完整流程和资金消耗节奏？"
- "SaaS公司的NDR（Net Dollar Retention）为什么比ARR更重要？"

**准备方法**：
- 对目标公司覆盖的1-2个赛道，建立"产业链地图"：上游（原材料/技术）→ 中游（制造/平台）→ 下游（渠道/用户），每个环节的关键玩家、商业模式、估值水平
- 读3-5篇该赛道的深度研报（中金/中信/招商），提炼出"如果我是投资人，我最关心哪三个问题"
- 关注该赛道的近期重大交易（并购/融资/上市），理解交易逻辑

## 四、差异化竞争力（如何脱颖而出）

| 竞争力类型 | 具体表现 | 为什么值钱 |
|:-----------|:---------|:-----------|
| **完整Deal经验** | 参与过从Sourcing到DD到交割到投后管理的全流程，能讲清楚自己在每个环节的角色 | 战投岗最怕"只做过研究、没碰过交易"，有Deal经验意味着上手快 |
| **特定行业"专家"身份** | 对某一赛道（如AI/新能源/生物医药/半导体）有超越同龄人的产业链认知，能说出让面试官惊讶的Insight | 战投按行业分组，行业专家能更快Source到好项目、更快完成DD |
| **财务+战略+业务三维能力** | 不仅懂估值建模，还懂战略设计，更懂业务落地（如做过产品经理/运营/销售） | 甲方战投需要"能写报告、能算模型、能推动业务"的复合人才 |
| **跨境/并购经验** | 有海外并购、跨境投资、VIE架构、外汇审批等复杂交易经验 | 中企出海和全球化是明确趋势，跨境交易能力稀缺 |
| **高层汇报经验** | 有直接向CXO/董事会汇报的经历，懂"高管语言"和"董事会关注点" | 战略部/战投部的客户就是CEO，能"向上管理"是核心竞争力 |
| **产业资源** | 有创业者网络、FA网络、行业专家库，能持续Source优质项目 | 战投岗的KPI不仅是"投得好"，还有"看得多、投得准" |

## 五、职业路径与可迁移方向

文本流程图

战略部路径：
战略分析师 / 商业分析师
   ↓ 2-3年
高级战略经理（独立负责战略项目/行业研究）
   ↓ 3-5年
战略总监（负责公司级战略规划、业务组合管理）
   ↓
VP of Strategy / Chief Strategy Officer（CSO）

战投部路径：
投资分析师 / 投资经理
   ↓ 2-3年
高级投资经理（独立负责Deal Sourcing到交割）
   ↓ 3-5年
投资总监（负责赛道布局、投后管理、退出策略）
   ↓
Head of Corporate Development / CFO（战投出身的CFO不少）

跨部门路径：
→ 业务线负责人（战略部/战投部转业务，如转去被投公司做CEO/COO）
→ 创业者（战略洞察+资本认知+产业资源，创业成功率较高）

Exit Options（跳槽方向）：
→ [[85-9 风险投资与私募]]（PE/VC，从CVC跳到纯财务投资）
→ [[85-1 管理咨询]]（少数从甲方跳回乙方，通常为了升Partner或换赛道）
→ [[85-2 投资银行与券商]]（去做Coverage或M&A Advisory）
→ 被投企业高管（CVC常见路径，投后派驻CEO/COO/CFO）
→ 创业（战略+资本+产业背景，适合产业互联网/硬科技创业）

## 六、准备时间线与行动清单

### 6.1 大二/大三早期阶段（筑基期）

- [ ] **建立商业分析框架**：
    
    - 精读《竞争战略》（波特）、《创新者的窘境》（克里斯坦森）、《好战略，坏战略》（鲁梅尔特）
        
    - 掌握：五力模型、价值链分析、SWOT、BCG矩阵、安索夫矩阵、蓝海战略
        
- [ ] **财务基础扎实**：
    
    - 系统学习《公司理财》（罗斯）、《财务报表分析》（佩因曼）
        
    - 能独立搭建DCF模型和简单的M&A模型
        
- [ ] **行业深度积累**：
    
    - 选择1-2个目标赛道（如AI/新能源/消费/医疗），建立"产业链地图"
        
    - 每周读1-2篇中金/中信深度研报，做笔记提炼核心观点
        
    - 关注该赛道的投融资动态（36氪/投中网/IT桔子）
        
- [ ] **第一段相关实习**：
    
    - 优先：咨询公司PTA（战略方向）、券商研究所（行业研究）、FA（财务顾问）
        
    - 其次：四大Transaction Service、企业战略部实习、投资机构实习
        
- [ ] **案例训练**：
    
    - 用咨询Case方法训练战略思维，但额外加入"组织可行性"和"财务回报"维度
        
    - 练习把Case答案写成1页Executive Summary（模拟董事会汇报）
        

### 6.2 大三/研一阶段（冲刺期）

- [ ] **Summer Intern**：全力冲刺头部企业战略部/战投部、MBB/投行/FA Summer
    
- [ ] **Deal/项目经验**：争取参与至少1个完整项目（从研究到汇报，或从Sourcing到DD）
    
- [ ] **财务建模进阶**：能熟练搭建Operating Model、M&A Model、LBO Model（战投方向）
    
- [ ] **行业专家访谈**：通过实习/校友网络，访谈3-5位行业专家，积累一手认知
    
- [ ] **Networking**：参加企业开放日、行业峰会、校友分享会，建立与在职战略/投资经理的联系
    

### 6.3 面试前3个月

- [ ] **公司战略诊断**：为每个目标公司写一份"战略评估报告"（业务组合、竞争态势、投资布局、建议方向）
    
- [ ] **财务模型Mock**：每周练习1-2个Modeling Case，追求速度和准确性
    
- [ ] **行业Deep Dive**：对目标赛道做到"面试官问任何细节都能答出三层"
    
- [ ] **行为题打磨**：准备"战略推动""跨部门博弈""高压决策"等甲方特有的故事
    
- [ ] **高管汇报模拟**：练习把复杂分析浓缩为3分钟Executive Summary，模拟向CEO汇报

## 八、常见误区


|误区|真相|
|:--|:--|
|"战略部就是写PPT的，战投部就是花钱的"|❌ 顶级战略部直接参与CEO决策，顶级战投部（如腾讯投资）的投资回报超过很多PE。这是离权力和资本最近的岗位之一|
|"应届生可以直接进战投"|❌ 极难。头部战投几乎不招应届生，或只招有2-3年咨询/投行经验的。应届生应先把咨询/投行/四大作为跳板|
|"战投比咨询轻松，因为是甲方"|❌ 战投项目周期长（6-18个月）、不确定性高、组织博弈复杂。压力不比咨询小，只是压力类型不同|
|"只要会估值建模就能进战投"|❌ 战投需要"战略+财务+业务"三维能力。纯财务背景的人容易陷入"只会算数、不懂业务"的陷阱|
|"CVC（企业战投）不如PE/VC专业"|❌ CVC有产业资源和战略协同优势，很多项目的回报和影响力超过纯财务投资机构。但CVC的决策链条更长，受母公司战略约束|
|"战略部决策了，业务部就会执行"|❌ 甲方最大的挑战是"推动执行"。战略部没有实权，全靠影响力和CEO支持。很多战略报告写完就束之高阁|
|"战投只看财务回报"|❌ CVC的核心逻辑是"战略协同"而非纯财务回报。投一个公司是为了补技术短板、拓渠道、防竞争，IRR只是考量之一|
