# 85-23 游戏行业（策划 / 运营 / 发行）

**定位**：游戏行业是“内容+科技”的复合型产业——它既需要创意（世界观、玩法、剧情），又需要技术（引擎、AI、图形学），还需要商业运营（商业化、发行、用户增长）。2026年上半年，国内游戏市场实际销售收入达1884.5亿元，同比增长12.17%，用户规模6.84亿，双双创下历史新高[reference:0][reference:1]。游戏行业已不是“小众爱好”，而是年产值数千亿的成熟产业。对于商科生来说，游戏行业的非技术岗位（策划、运营、发行、商业化）是进入这个产业的“入口”——不需要写代码，但需要对游戏有深刻理解、对用户有敏锐洞察、对数据有分析能力。

**适合人群画像**：游戏经历丰富且能“玩出门道”——不只是“玩过很多游戏”，而是能分析“为什么这个设计好、那个设计不好”；对用户心理有洞察力；有较强的逻辑思维和数据分析能力；沟通能力强、能协调多方资源；抗压能力强（游戏行业节奏快、版本迭代频繁）；对某一品类（如SLG、二次元、MMO）有深度理解是加分项。

**行业格局**：

- **按公司类型分**：研发型（自研游戏）、发行型（代理发行）、研运一体型（既研发又运营）
- **按平台分**：移动游戏（基本盘，2026上半年收入1352.10亿元，占市场71.8%）、客户端游戏（增长亮眼，收入452.88亿元，同比+27.92%）、小程序游戏（爆发式增长，收入316.57亿元，同比+36.01%）、主机游戏、网页游戏[reference:2]
- **按品类分**：二次元、SLG（策略）、MMO（大型多人在线）、卡牌、射击、开放世界、休闲等
- **按职能分**：策划类、运营类、发行/市场类、技术类、美术类、项目管理类[reference:3]


## 一、核心能力矩阵

### 1.1 游戏策划（Game Designer）

游戏策划是游戏产品的“定义者”——负责设计游戏的核心玩法、系统、数值、关卡、剧情等，是游戏从0到1的起点。

| 能力维度 | 权重 | 说明 |
|:---------|:----:|:-----|
| **游戏理解与拆解能力** | ★★★ | 核心门槛。不只是“玩过很多游戏”，而是能拆解“这个游戏为什么好玩”——核心循环是什么？付费点在哪里？用户为什么留下来？ |
| **逻辑思维与系统设计** | ★★★ | 游戏是复杂的系统——数值平衡、经济系统、成长曲线、反馈机制都需要严密的逻辑设计[reference:4] |
| **文档与沟通能力** | ★★★ | 策划的核心产出是“需求文档”——要把设计思路清晰地写出来、讲给程序和美术听，并推动落地[reference:5] |
| **数据分析能力** | ★★☆ | 上线后的数据反馈是验证设计的最佳方式——需要能看懂留存、付费、关卡通过率等数据[reference:6] |
| **用户洞察与共情** | ★★☆ | 理解玩家在不同场景下的心理——挫败感、成就感、社交需求、付费动机[reference:7] |
| **工具技能** | ★★☆ | Excel（数值策划必备）、原型工具、引擎编辑器基础、AI辅助策划工具[reference:8][reference:9] |

### 1.2 游戏运营（Game Operations）

游戏运营是游戏上线后的“操盘手”——负责版本管理、商业化、活动策划、用户运营，让游戏持续产生收入和口碑[reference:10][reference:11]。

| 能力维度 | 权重 | 说明 |
|:---------|:----:|:-----|
| **运营策略制定** | ★★★ | 制定版本节奏、商业化规划、活动排期等全盘运营策略[reference:12][reference:13] |
| **数据分析能力** | ★★★ | 从用户行为数据中发现问题、验证策略——活跃、付费、留存、流失等核心指标[reference:14][reference:15] |
| **商业化与活动设计** | ★★★ | 设计游戏内付费点、定价策略、促销活动，提升ARPU和LTV[reference:16][reference:17] |
| **用户运营能力** | ★★☆ | 用户分层、社区运营、大客户维护、舆情管理[reference:18] |
| **产品思维** | ★★☆ | 能基于玩家反馈和数据，向研发提出产品优化建议[reference:19] |
| **沟通与跨部门协作** | ★★☆ | 协调研发、市场、客服等多方资源[reference:20] |

### 1.3 游戏发行与市场（Game Publishing & Marketing）

游戏发行是“让游戏被看见、被下载、被付费”的职能——负责渠道合作、广告投放、品牌营销、社区运营等[reference:21]。

| 能力维度 | 权重 | 说明 |
|:---------|:----:|:-----|
| **渠道与投放能力** | ★★★ | 熟悉App Store、Google Play、TapTap及各买量渠道的玩法[reference:22] |
| **营销策划能力** | ★★★ | 策划并执行游戏上线/版本的营销战役[reference:23] |
| **数据分析能力** | ★★☆ | 投放ROI分析、用户获取成本（CAC）优化[reference:24][reference:25] |
| **内容与社区运营** | ★★☆ | 攻略、视频、KOL合作、社区氛围建设[reference:26] |
| **商务谈判能力** | ★★☆ | 渠道合作、IP联动、异业合作[reference:27] |
| **外语能力** | ★★☆ | 海外发行岗位需英语/日语/韩语等作为工作语言[reference:28] |

### 1.4 行业通用能力

| 能力维度 | 权重 | 说明 |
|:---------|:----:|:-----|
| **热爱游戏** | ★★★ | 不是“喜欢玩游戏”，而是“对游戏有深度理解和研究”——这是所有游戏岗位的“入场券”[reference:29][reference:30] |
| **数据驱动** | ★★★ | 游戏行业是“数据密度最高”的行业之一——每个玩家的每一步操作都可追踪[reference:31] |
| **抗压与迭代能力** | ★★☆ | 版本节奏快、上线压力大、玩家反馈直接——需要快速调整心态和策略 |
| **AI工具应用能力** | ★★☆ | AI已全面渗透游戏产业链——从内容生成到用户分析，AI相关复合型岗位薪资靠前[reference:32][reference:33] |


## 二、硬门槛与准入条件

| 门槛类型 | 具体要求 |
|:---------|:---------|
| **学历背景** | 本科及以上，专业不限。985/211有优势但非必须——**游戏理解和项目经验远比学历重要** |
| **专业背景** | **完全不卡专业**。计算机/理工科背景在数值策划、技术策划中有优势；文科/商科背景在剧情策划、运营、发行中有优势 |
| **游戏经历** | **绝对的硬通货**——不是“玩过很多游戏”，而是“对至少1-2款游戏有深度理解”（能分析核心玩法、付费设计、用户留存逻辑）[reference:34] |
| **实习经历** | 游戏公司相关实习是简历筛选的核心依据。没有实习，必须有**可展示的游戏设计作品**（策划案、数值模型、分析报告等）|
| **作品集** | 策划岗尤其重要——包含：游戏拆解报告、策划方案文档、数值模型、关卡设计等[reference:35] |
| **数据能力** | 运营/发行岗需掌握Excel高级功能；SQL是加分项[reference:36][reference:37] |
| **英语能力** | 海外发行岗位要求英语可作为工作语言[reference:38] |


## 三、面试考察全景图

### 3.1 项目深挖（Project Deep Dive）

**占比**：40-50%

面试官会深挖你简历上的游戏相关项目——实习、竞赛、个人作品、甚至深度体验过的游戏。

| 层级 | 典型问题 | 考察点 |
|:-----|:---------|:-------|
| **理解层** | “你最喜欢的游戏是什么？为什么好玩？” | 游戏理解深度，是否能从玩家视角切换到设计视角 |
| **拆解层** | “这个游戏的核心循环是什么？付费点在哪里？” | 系统思维、结构化拆解能力 |
| **分析层** | “如果让你优化这个游戏的XX系统，你会怎么做？” | 产品思维、设计能力 |
| **数据层** | “这个游戏上线后数据怎么样？你怎么分析的？” | 数据分析能力 |
| **反思层** | “如果重新设计这个系统，你会怎么改进？” | 复盘能力、迭代思维 |

**致命雷区**：
- ❌ “我喜欢这个游戏，因为好玩”——没有深度分析，等于没回答
- ❌ “这个功能是老板/导师让我做的”——缺乏Ownership
- ❌ “数据挺好的”——没有具体数字，显得不专业

### 3.2 专业问题

**占比**：30-40%

#### 题型一：游戏拆解

**典型问题**：“请拆解一款你熟悉的游戏的核心玩法、经济系统和付费设计。”

**答题框架**：
1. **核心玩法**：玩家每局/每天在做什么？核心循环是什么？
2. **经济系统**：货币体系、产出与消耗、交易机制
3. **付费设计**：付费点在哪？为什么要付费？付费和不付费玩家的体验差异
4. **用户留存**：玩家为什么留下来？什么机制让玩家“明天还想玩”？
5. **可改进点**：如果让你优化，你会改什么？

**关键加分点**：能说出“这个设计为什么有效”，而不是只描述“有什么”

#### 题型二：策划方案

**典型问题**：“设计一个‘节日活动’方案，目标是提升7日留存和付费率。”

**答题框架**：
1. **目标定义**：具体目标是什么？（留存提升X%？付费率提升X%？）
2. **用户洞察**：目标用户是谁？他们在节日期间想要什么？
3. **活动设计**：活动形式、奖励机制、参与门槛
4. **商业化设计**：付费点在哪里？怎么让玩家“想花钱”？
5. **数据验证**：怎么衡量活动效果？关键指标是什么？

#### 题型三：运营分析

**典型问题**：“游戏上线后首周DAU很高，但第2周留存率大幅下降，你会怎么分析？”

**答题框架**：
1. **数据诊断**：下降发生在哪个节点？哪个用户群体下降最严重？
2. **内容分析**：第2周的游戏内容是否有问题？（难度曲线、内容消耗速度、新手引导）
3. **用户反馈**：玩家在社区、评价中说了什么？
4. **竞品对比**：竞品同期的留存数据如何？是行业现象还是自身问题？
5. **解决方案**：短期（活动/补偿）vs 长期（内容/系统优化）

### 3.3 行为面试（Behavioral）

**占比**：10-20%

| 场景 | 典型问题 | 考察点 |
|:-----|:---------|:-------|
| **版本压力** | “游戏版本上线前发现重大Bug，你怎么处理？” | 抗压能力、应急处理 |
| **跨部门冲突** | “策划方案被程序否决了，怎么办？” | 沟通能力、灵活性 |
| **玩家舆情** | “游戏更新后玩家大量差评，你怎么应对？” | 危机处理、用户思维 |
| **数据不达预期** | “策划的活动数据很差，怎么复盘？” | 复盘能力、成长型思维 |


## 四、差异化竞争力

| 竞争力类型 | 具体表现 | 为什么值钱 |
|:-----------|:---------|:-----------|
| **深度游戏理解** | 能拆解至少2-3款游戏的完整设计逻辑（核心玩法、经济系统、付费模型、用户画像）| 证明你不是“玩家”，而是“懂游戏设计的人” |
| **数据分析项目** | 有用数据驱动游戏分析/运营决策的项目经验 | 游戏行业“数据密度高”，数据分析能力是稀缺资源 |
| **AI工具应用** | 能用AI辅助游戏内容生成、数据分析、用户画像等 | AI相关复合型岗位薪资靠前[reference:39] |
| **特定品类深耕** | 对某一品类（SLG、二次元、MMO、卡牌等）有深度认知和实践 | 品类经验难以快速迁移，深耕者是稀缺人才 |
| **出海/全球化视野** | 有海外游戏市场研究经验、多语言能力 | 游戏出海是行业确定性趋势[reference:40] |
| **个人游戏作品** | 独立完成过游戏设计文档、数值模型、甚至可玩原型 | 证明你能“把想法变成可执行方案” |


## 五、可迁移方向

- → 互联网产品经理（游戏策划转产品经理，产品思维可迁移）

## 六、准备时间线与行动清单

### 6.1 大二阶段

- [ ] **建立游戏理解深度**
    - [ ] 挑选1-2款游戏深度体验（至少50小时以上），写“游戏拆解报告”（核心玩法、经济系统、付费设计、留存机制）
    - [ ] 每周拆解1款热门游戏的版本更新和活动，理解“为什么这样做”
    - [ ] 关注游戏行业媒体（游戏葡萄、GameRes、触乐）

- [ ] **基础能力建设**
    - [ ] 掌握Excel高级功能（数值策划方向必备）
    - [ ] 学习基础数据分析（SQL、数据可视化）
    - [ ] 尝试用AI工具辅助游戏分析和内容生成

- [ ] **第一份相关实习/项目**
    - [ ] 优先：游戏公司策划/运营实习
    - [ ] 其次：游戏相关竞赛（Game Jam、游戏策划大赛）
    - [ ] 再次：独立完成一份游戏策划方案或拆解报告作为作品

- [ ] **作品集积累**
    - [ ] 整理至少2份游戏拆解报告
    - [ ] 完成1份完整的游戏策划方案
    - [ ] 如有条件，参与1次Game Jam产出可玩原型

### 6.2 大三阶段

- [ ] **深度实习**
    - [ ] 目标：头部游戏公司（腾讯、网易、米哈游、莉莉丝等）的策划/运营/发行实习
    - [ ] 在实习中争取拿到“可量化的成果”和“可讲的故事”

- [ ] **品类深耕**
    - [ ] 选择1-2个品类深度研究（SLG、二次元、MMO、卡牌等）
    - [ ] 研究该品类的头部产品、用户画像、商业化模型

- [ ] **数据能力进阶**
    - [ ] 掌握SQL（能从数据库取数分析游戏数据）
    - [ ] 能用数据回答“为什么这个版本数据好/不好”

- [ ] **面试题库训练**
    - [ ] 准备“游戏拆解题”的答题框架
    - [ ] 准备“策划方案题”的答题框架
    - [ ] 准备“运营分析题”的答题框架
    - [ ] 准备8-10个STAR行为面试故事

### 6.3 面试前3个月

- [ ] **作品集打磨**：整理成可直接发给面试官的链接或PDF
- [ ] **项目深挖清单**：为简历上每个项目准备“三层追问”的答案
- [ ] **品类准备**：准备1-2个品类的深度分析（市场规模、头部产品、用户画像、趋势）
- [ ] **模拟面试**：找在职游戏行业从业者或求职伙伴做Mock Interview

## 八、常见误区

| 误区 | 真相 |
|:-----|:-----|
| “游戏行业=打游戏” | ❌ 游戏行业是“做游戏”的——策划要写文档、运营要看数据、发行要做投放。热爱游戏是前提，但不是全部 |
| “不玩游戏也能做游戏策划” | ❌ 游戏策划的核心能力是“游戏理解”——没有足够的游戏积累，就无法判断“什么设计好、什么不好” |
| “游戏策划就是写故事的” | ❌ 剧情策划只是策划的一个细分方向。更多策划在做系统设计、数值平衡、关卡设计——需要逻辑和数学能力 |
| “游戏行业都是996” | ⚠️ 游戏行业节奏确实快，版本上线、活动节点压力大，但不同公司差异很大——头部公司有完善的管理制度，加班强度可控 |
| “游戏运营=客服” | ❌ 游戏运营是“用策略驱动游戏增长”——版本规划、商业化设计、活动策划、数据归因，都是运营的核心工作[reference:41] |
| “游戏行业只有技术岗有前途” | ❌ 策划、运营、发行等非技术岗是游戏行业的核心职能——游戏的成功不仅取决于技术，更取决于“好不好玩”“运营得好不好”“发得好不好” |
