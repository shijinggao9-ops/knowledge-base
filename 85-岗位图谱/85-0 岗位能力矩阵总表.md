## 二、岗位能力画像与准备路径

### 85-1 管理咨询
**核心能力组合**：结构化思维（MECE/假设驱动）+ 商业洞察 + 高强度交付
**硬门槛**：Target School 背景、高 GPA、Case 拆解能力
**面试考察重点**：结构化表达、Market Sizing、profitability 案例、PPT 故事线
**差异化竞争力**：特定行业深度（如医疗、TMT）、领导力经历、多语言
**可迁移方向**：[[85-8 企业战略与战投]] → [[85-9 风险投资与私募]] → [[85-5 互联网产品经理]]
**准备周期**：3-6 个月（Case 训练为主）

### 85-2 投资银行与券商
**核心能力组合**：财务分析（估值建模/三张表）+ 行业认知 + 细致零差错
**硬门槛**：财务功底、相关实习（承做/承销）、CPA/CFA 进度
**面试考察重点**：Technical Questions（DCF/LBO/会计）、行业理解、Deal 经验
**差异化竞争力**：完整项目经历、特定行业覆盖（如新能源、半导体）、法规熟悉度
**可迁移方向**：[[85-8 企业战略与战投]] → [[85-9 风险投资与私募]] → [[85-3 四大会计师事务所]]
**准备周期**：6-12 个月（财务基础+实习积累）

### 85-3 四大会计师事务所
**核心能力组合**：财务分析 + 数据处理 + 抗压细致 + 审计方法论
**硬门槛**：会计基础、Excel 熟练、能接受出差和忙季
**面试考察重点**：会计知识（IFRS/GAAP）、审计流程理解、团队合作、职业稳定性
**差异化竞争力**：CPA 通过门数、特定行业审计经验、数据分析工具（Power BI/SQL）
**可迁移方向**：[[85-2 投资银行与券商]] → [[85-8 企业战略与战投]] → [[85-13 供应链与采购]]（内控方向）
**准备周期**：2-3 个月（会计+面试准备）

### 85-4 快消
**核心能力组合**：商业洞察 + 沟通表达 + 项目管理 + 消费者洞察
**硬门槛**：对品牌和消费者的敏感度、英文能力、相关实习
**面试考察重点**：商业案例分析、品牌理解、领导力经历、多任务处理
**差异化竞争力**：用户运营经验、内容创作能力、数据分析辅助决策、海外背景
**可迁移方向**：[[85-11 品牌公关与广告]] → [[85-6 互联网运营]] → [[85-10 市场研究与用户研究]]
**准备周期**：3-4 个月（Case+品牌洞察积累）

### 85-5 互联网产品经理
**核心能力组合**：商业洞察 + 项目管理 + 工具技能（原型/流程）+ 沟通协同
**硬门槛**：产品实习经历、Axure/Figma 原型能力、需求文档撰写
**面试考察重点**：产品思维（用户-场景-需求）、项目复盘、数据驱动决策、技术理解
**差异化竞争力**：完整产品迭代经历、技术背景、特定领域深度（如 AI/出海）
**可迁移方向**：[[85-6 互联网运营]] → [[85-8 企业战略与战投]] → [[85-4 快消]]（数字化方向）
**准备周期**：3-6 个月（项目+实习）

### 85-6 互联网运营
**核心能力组合**：数据分析 + 项目管理 + 沟通表达 + 用户洞察
**硬门槛**：运营实习、数据敏感度、对流量逻辑的理解
**面试考察重点**：运营案例拆解（AARRR）、数据指标定义、活动策划复盘、增长思维
**差异化竞争力**：从 0 到 1 项目经验、内容/社群/投放某一领域深度、SQL/Python
**可迁移方向**：[[85-5 互联网产品经理]] → [[85-4 快消]]（电商/数字化） → [[85-14 销售与商务拓展]]
**准备周期**：2-4 个月（实习为主）

### 85-7 数据分析
**核心能力组合**：数据分析 + 工具技能（SQL/Python/BI）+ 结构化思维 + 细致交付
**硬门槛**：SQL 熟练、统计学基础、数据可视化能力
**面试考察重点**：SQL 笔试、业务指标拆解（漏斗/归因）、A/B 测试设计、商业理解
**差异化竞争力**：业务场景理解（如电商/金融）、算法基础、自动化报表搭建
**可迁移方向**：[[85-5 互联网产品经理]]（数据 PM） → [[85-6 互联网运营]]（增长） → [[85-10 市场研究与用户研究]]
**准备周期**：3-6 个月（SQL+统计学+项目）

### 85-8 企业战略与战投
**核心能力组合**：商业洞察 + 财务分析 + 行业认知 + 沟通表达
**硬门槛**：咨询/投行/研究背景、行业研究深度、财务建模
**面试考察重点**：行业研究框架、投资逻辑、Deal 分析、战略规划思路
**差异化竞争力**：特定行业深耕（如硬科技、消费）、完整项目经验、产业资源
**可迁移方向**：[[85-9 风险投资与私募]] → [[85-1 管理咨询]] → [[85-2 投资银行与券商]]
**准备周期**：6-12 个月（行业深度+财务基础）

### 85-9 风险投资与私募
**核心能力组合**：商业洞察 + 财务分析 + 行业认知 + 沟通表达
**硬门槛**：一线机构实习、行业研究能力、对商业模式的深刻理解
**面试考察重点**：项目判断逻辑、行业趋势判断、估值方法、Source 能力
**差异化竞争力**：产业背景、技术理解（如 AI/生物）、创始人网络、特定赛道深耕
**可迁移方向**：[[85-8 企业战略与战投]] → [[85-1 管理咨询]] → [[85-2 投资银行与券商]]
**准备周期**：6-12 个月（实习+行业积累）

### 85-10 市场研究与用户研究
**核心能力组合**：数据分析 + 商业洞察 + 工具技能（SPSS/Python/定性方法）+ 行业认知
**硬门槛**：研究方法论（定量/定性）、数据分析工具、报告撰写
**面试考察重点**：研究设计（问卷/访谈）、数据分析逻辑、洞察提炼、汇报呈现
**差异化竞争力**：特定行业研究经验、用户心理学基础、大数据工具、跨文化研究
**可迁移方向**：[[85-4 快消]]（消费者洞察） → [[85-5 互联网产品经理]]（用户研究） → [[85-11 品牌公关与广告]]
**准备周期**：3-4 个月（方法+项目）

### 85-11 品牌公关与广告
**核心能力组合**：沟通表达 + 项目管理 + 行业认知 + 创意与文案
**硬门槛**：文案能力、审美与排版、对传播逻辑的敏感
**面试考察重点**：品牌案例拆解、Campaign 策划、危机公关思路、资源整合
**差异化竞争力**：内容创作数据（如自媒体）、4A 实习、特定圈层洞察、双语能力
**可迁移方向**：[[85-4 快消]]（MKT） → [[85-6 互联网运营]]（内容） → [[85-15 商务达人建联]]
**准备周期**：2-4 个月（作品集+实习）

### 85-12 人力资源与组织发展
**核心能力组合**：沟通表达 + 抗压细致 + 数据分析（人力方向）+ 项目管理
**硬门槛**：对人和组织的敏感度、服务意识、多任务处理能力
**面试考察重点**：HR 模块理解（TD/OD/OC/BP）、案例分析、行为面试、职业稳定性
**差异化竞争力**：数据分析辅助 HR 决策（如漏斗分析）、组织行为学理论、心理学背景
**可迁移方向**：[[85-4 快消]]（HRBP） → [[85-8 企业战略与战投]]（组织方向） → [[85-1 管理咨询]]（人力资本）
**准备周期**：2-3 个月（理论+实习）

### 85-13 供应链与采购
**核心能力组合**：项目管理 + 数据分析 + 行业认知 + 抗压细致
**硬门槛**：对供应链流程的理解、成本意识、Excel 与 ERP 系统
**面试考察重点**：供应链优化案例、库存管理逻辑、供应商谈判、成本分析
**差异化竞争力**：特定行业供应链经验（如汽车、医药）、数字化供应链工具、跨地域协调
**可迁移方向**：[[85-4 快消]]（供应链管培） → [[85-3 四大会计师事务所]]（内控） → [[85-14 销售与商务拓展]]

**面试考察重点**：销售案例（如何拿下客户）、抗压与拒绝处理、目标拆解、资源整合
**差异化竞争力**：客户资源积累、特定行业深度、数据分析辅助销售决策、外语能力
**可迁移方向**：[[85-15 商务达人建联]] → [[85-4 快消]]（KA） → [[85-8 企业战略与战投]]（BD）

### 85-15 商务达人建联
