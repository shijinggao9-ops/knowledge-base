# Week 8 — Exercises

Three exercises, building in order: map a flow, test a flow, critique a screen. Do them in sequence — Exercise 2 reuses the flow you mapped in Exercise 1, and Exercise 3's screen comes from the same flow.

## What you need

- The `usability_sessions` table set up in the [week README](../README.md#set-up-the-usability-log-table) (Exercise 2 only).
- Five people willing to spend 10–15 minutes each on a think-aloud session (Exercise 2). Coworkers, classmates, friends, family — fresh eyes matter more than domain expertise.
- No design tool required. All flows and screens are given as labeled text/ASCII wireframes.

## How to work them

1. Read the exercise fully before starting — several have a setup step (SQL table, printed task script) you'll want ready before you begin timing yourself or a participant.
2. Do the work for real. Exercise 2 in particular only teaches you anything if you run actual sessions with actual people — don't simulate the data.
3. Save your work to your portfolio, in a folder per exercise (paths noted at the bottom of each file), the same way you have every week.
