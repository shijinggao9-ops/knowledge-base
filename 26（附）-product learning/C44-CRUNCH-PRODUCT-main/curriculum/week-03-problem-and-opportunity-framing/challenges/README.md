# Week 3 — Challenges

Two challenges, both harder and more open-ended than the exercises. Where the exercises taught you the mechanics (writing a statement, running a query, drawing a tree), these challenges put you in the uncomfortable position a real PM ends up in constantly: defending an unpopular call, and explaining a number that doesn't add up. There is no single right answer to either — there is a **defensible** answer and an indefensible one, and the difference is in how well you show your reasoning.

## How to work them

- Do these after all three exercises — both challenges assume you're fluent with problem statements, sizing, and opportunity trees.
- Neither challenge has an answer key. Judge your own work against the rubric in each file, and ideally trade write-ups with a classmate or peer reviewer — these are exactly the kind of documents that improve the most from a second reader.
- Budget real time for these — they're not quick. Both are written-artifact challenges (a memo, an analysis write-up), not quiz questions.
