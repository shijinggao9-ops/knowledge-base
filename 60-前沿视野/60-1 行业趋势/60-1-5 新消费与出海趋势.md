# 60-1-5 新消费与出海趋势

> **更新日期**：2026年8月8日
> **定位**：本文档为“60-前沿视野”行业趋势系列之五，聚焦中国消费市场的结构性变化与出海趋势——从“买商品”到“买服务”的消费换轨，从“产品输出”到“品牌+产能+体系”协同输出的出海升级。


## 一、消费市场总览：从“买商品”到“买服务”

### 1.1 消费引擎换轨：服务消费成为主引擎

2026年上半年，中国消费市场正经历一场深刻的结构性转折。7月15日，国家统计局首次将“社会消费商品和服务零售总额”合并发布，传统的“社零”单轨制正式转向“商品+服务”双轨并重[reference:0]。

**核心数据**：
- 上半年社会消费商品和服务零售总额同比增长 **2.7%**[reference:1]
- 服务零售额增长 **5.3%**，增速高于商品零售额 **4.2个百分点**[reference:2]
- 商品零售额仅增长 **1.1%**[reference:3]
- 传统“社零”口径下，4月增速仅0.2%，5月甚至出现 **-0.6%** 的负增长，为2023年以来首次[reference:4][reference:5]

**统计“换尺子”的信号意义**：国家统计局将服务零售额并入消费数据，本身就是强烈的信号——这反映了对中国消费结构分化现实的认同，也意味着政策靶向将有所转变[reference:6]。

**国际规律**：当人均GDP达到1.5万美元左右时，居民消费结构将加快从商品消费主导向服务消费主导转变。2025年中国人均GDP约1.4万美元，恰好站在这一历史门槛上[reference:7]。2025年居民人均服务性消费支出占比已达 **46.1%**，在北京、上海等一线城市已接近 **60%**[reference:8][reference:9]。

### 1.2 “十五五”消费规划：60万亿目标

2026年7月13日，国务院批复《扩大消费“十五五”规划》，这是**中国首部消费领域的国家级专项规划**[reference:10]。

**核心目标**：到2030年，社会消费品零售总额达到 **60万亿元** 左右[reference:11][reference:12]。

| 指标 | 数据 | 说明 |
|:-----|:----:|:-----|
| 2025年社零规模 | 50.1万亿元 | 已突破50万亿大关[reference:13] |
| 2030年目标 | 60万亿元 | 对应2026-2030年复合增速约3.7%[reference:14] |
| 2027-2030年要求 | 需年均4.2%以上[reference:15] | 考虑到2026年消费惯性偏弱[reference:16] |

**政策逻辑之变**：从“短期刺激”转向“制度驱动”——消费能力不再是配套措施，而是前置条件[reference:17]。首次将养老、托育、文旅、健康等服务消费置于突出位置，并明确提出推动带薪休假制度落地[reference:18]。


## 二、新消费三大引擎

机构认为，AI+消费、情绪经济、新质零售分别从技术端、需求端、供给端三大维度引领新消费变革[reference:19]。

### 2.1 引擎一：AI+消费

截至2025年上半年，我国生成式AI产品用户规模已达 **5.15亿**（较2024年12月增长2.66亿），普及率36.5%[reference:20]。“AI+消费”有望形成“需求牵引技术、技术创造需求”的循环[reference:21]。

**具体体现**：
- AI助手一键下单已超 **1.2亿次**[reference:22]
- 具身智能机器人已进入智慧药房等消费场景[reference:23]
- AI眼镜、AI玩具等新品类的爆发[reference:24]
- 2026世界人工智能大会（WAIC）上，小型智能玩偶、AI萌宠等轻量化AI消费产品大量涌现[reference:25]

### 2.2 引擎二：情绪经济

情绪消费市场规模快速攀升，形成 **4.5万亿元新蓝海**[reference:26]。

| 年份 | 情绪消费市场规模 |
|:-----|:----------------:|
| 2022年 | 1.63万亿元[reference:27] |
| 2025年（预计）| 2.72万亿元[reference:28] |
| 2029年（预计）| 4.5万亿元[reference:29] |

**驱动因素**：
- Z世代人口占比提升，消费从“功能满足”向“情绪共鸣”转变[reference:30]
- “孤独经济”与AI技术落地的双重驱动[reference:31]
- AI玩具赛道爆发：兼具潮玩属性与AI情感交互能力的智能陪伴硬件成为风口[reference:32]

**消费场景拓展**：潮玩IP、二次元、黄金珠宝IP联名、AI宠物、文旅体验等众多赛道，情感链接正在重塑消费选择逻辑[reference:33]。

### 2.3 引擎三：新质零售

从传统零售到新质零售，核心是从“渠道端变革”升级为“消费体验与分级”的供给端优化[reference:34]。

| 案例 | 表现 |
|:-----|:-----|
| 山姆中国 | 2025年销售额突破1400亿，同比增长40%，线上业务占比50%[reference:35] |
| 县域消费 | 县乡消费占社零总额比重提升至 **39.2%**[reference:36] |
| 即时零售 | 以前置仓为基本盘的新零售模式持续扩张[reference:37] |


## 三、出海：从“走出去”到“扎下根”

### 3.1 出海进入“质变期”

2026年被罗兰贝格定义为中企从“**规模化出海**”向“**高质量全球化**”转型的关键节点[reference:38]。

**演进路径**：

产能出海 → 产品出海 → 服务出海（初级阶段）  
↓  
品牌出海（高阶形态）

核心诉求从“走出去”转向“**扎下根**”[reference:39]。国信证券指出，2026年A股公司出海已告别单纯商品出口阶段，进入**产能、品牌、管理体系协同输出的质变期**[reference:40]。

**“中国制造”到“中国创造”**：瑞银指出，出海是未来5至10年的核心主题，中企将推动竞争力从“Made-in-China”升级到“**Made-by-China**”[reference:41]。

**四大出海模式**：中国企业已形成以品牌产品、制造能力、技术创新与产业服务为核心的四大出海模式——消费出海、产能出海、科技出海与服务出海[reference:42]。

### 3.2 新能源汽车出海

2026年上半年，中国汽车出口 **509.6万辆**，同比增长 **65.3%**；6月单月出口**首次突破百万辆**【60-1-2†相关数据】。

**从“产品输出”到“体系输出”**：中国汽车出口正从产品输出向技术输出、产能输出、品牌输出和产业链输出转变[reference:43]。海外本地化生产成为突破贸易壁垒、降低成本、融入区域市场的重要战略选择[reference:44]。

### 3.3 跨境电商：“四小龙”的战略调整

中国跨境电商正经历深刻洗牌——“中国跨境电商四小龙”（TEMU、SHEIN、速卖通、TikTok Shop）几乎同时进入战略调整期[reference:45]。

**核心变化**：
- 从“**全托管神话**”到“**半托管回归**”[reference:46]
- 从“价格战”转向“**价值战**”[reference:47]
- 从“效率故事”演变为“**合规故事、本地化故事、品牌化故事**”[reference:48]

**驱动因素**：

| 挑战 | 影响 |
|:-----|:-----|
| 小额包裹免税政策取消 | 美国、欧盟、英国、日本、巴西等已取消或提议取消，直邮小包模式受冲击[reference:49] |
| 关税政策反复 | 综合成本上升[reference:50] |
| 海外监管持续加码 | 合规要求提升[reference:51] |
| 生成式AI加速渗透 | 竞争逻辑重塑[reference:52] |

**平台应对**：
- **速卖通**：将“品牌出海+海外托管”作为2026年核心关键词[reference:53]
- **TEMU**：拼多多联席CEO表态“All in 中国供应链的高质量、品牌化”[reference:54]
- **SHEIN**：从“AI设计+小单快反”转向品牌化，开始对部分商品调涨价格[reference:55][reference:56]
- **TikTok Shop**：从“纯流量平台”向“货架+内容”转身[reference:57]

### 3.4 新市场：拉美成为新蓝海

当北美流量红利见顶、东南亚赛道拥挤，拉美正成为最炙手可热的蓝海[reference:58]。

**市场规模**：2026年拉美电商销售额预计达 **2153.1亿美元**（约1.46万亿元人民币），增速是全球平均水平的 **1.5倍**[reference:59]。

| 指标 | 数据 |
|:-----|:-----|
| 巴西电商行业收入（2025年）| 超2000亿雷亚尔（约2774亿元），同比增长超10%[reference:60] |
| 巴西人口 | 超2亿[reference:61] |
| 美客多中国卖家增长 | 过去两年实现三位数高速增长[reference:62] |

**挑战**：随着巴西、墨西哥相继取消小额包裹免税，曾经靠“低价包邮”收割红利的打法已然失效[reference:63]。

### 3.5 出海趋势展望

1. **本地化成为必答题**：中企必须在海外打造新的发展与竞争策略——提供适应当地需求的产品、设计本地化营销、搭建当地销售渠道、开设海外研发中心[reference:64]。

2. **品牌化是价值跃迁的关键**：从价格竞争转向品牌竞争，以品牌溢价消化成本增量[reference:65]。

3. **“新三样”持续升级**：从“能源新三样”（新能源车、锂电池、光伏）向“**智能新三样**”（汽车智能、低空经济、具身智能）演进。

4. **全球化2.0**：在初步享受出海红利后，企业面临的核心命题转向深度化、精细化运营，包括风险防控、差异化管控与本地合规[reference:66]。


## 四、未来展望

1. **消费换轨不可逆转**：服务消费增速将持续快于商品消费，预计“十五五”期间服务消费占比将进一步提升[reference:67]。

2. **60万亿目标可期但挑战不小**：耐用品修复是最大变量，补贴带来的需求预支可能持续至2027年9月[reference:68]；非耐用品和服务是消费的稳定器[reference:69]。

3. **出海从“选择题”变“必答题”**：出海是未来5-10年的核心主题[reference:70]。2026年是中企高质量全球化转型的关键节点[reference:71]。

4. **跨境电商进入品牌化新阶段**：全托管退潮，半托管/海外托管成为新主流，品牌化是价值跃迁的关键[reference:72]。
