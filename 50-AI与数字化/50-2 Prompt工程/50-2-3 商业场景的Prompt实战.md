**适用场景**：日常工作汇报、竞品分析与行业研究、营销内容创作、数据处理与报告生成、面试准备与模拟、学习与信息整理。


## 一、商业分析场景

商业分析是商科生最核心的工作场景之一——包括行业分析、竞品分析、市场进入分析和数据分析。这类场景的Prompt设计需要强调：**结构清晰、推理可见、边界明确**。

### 场景1：行业分析

**核心需求**：快速了解一个行业的规模、趋势、竞争格局和关键玩家。

**设计思路**：
- 角色设定：行业分析师或战略顾问
- 任务拆解：规模→趋势→竞争→关键玩家→机会
- 输出格式：结构化（分模块）+ 可验证（标注来源）

**可复用模板**：
【角色设定】  
你是一名资深行业分析师，有8年专注于[XX行业]的研究经验，擅长从数据中提炼洞察。

【任务描述】  
请对[XX行业]进行一次系统性分析，覆盖以下五个维度：

1. 行业规模：当前市场规模、增速、未来3年预测
    
2. 行业趋势：正在发生的3个关键趋势及其驱动力
    
3. 竞争格局：TOP5玩家的市场份额、核心优势和差异化策略
    
4. 关键玩家：2-3家代表性公司的商业模式深度分析
    
5. 机会与风险：2个最大的机会和2个最大的风险
    

【背景信息】

- 时间范围：当前至2028年
    
- 地域范围：[中国/全球/特定区域]
    
- 目标受众：公司决策层（需要结论驱动、数据支撑）
    

【输出格式】  
分五个部分，每部分用小标题标注。每部分包含：

- 核心结论（1-2句话）
    
- 支撑证据（数据、案例）
    
- 对决策者的启示（1-2句话）
    

【约束条件】

- 所有数据需标注来源（如“据XX报告”）
    
- 不确定的数据明确标注“据估算”
    
- 避免泛泛而谈，每部分至少有一个具体的数据点
    
- 总字数控制在1500-2000字
    

**使用示例**：
> “请对‘中国现制茶饮行业’进行一次系统性分析，覆盖行业规模、行业趋势、竞争格局、关键玩家、机会与风险五个维度。目标受众是公司决策层，需要结论驱动、数据支撑。分五个部分，每部分包含核心结论、支撑证据和决策启示。所有数据需标注来源。”
### 场景2：竞品分析
**核心需求**：了解竞争对手的产品、策略、优劣势和动向。
**设计思路**：
- 角色设定：产品/战略分析师
- 任务拆解：产品对比→策略分析→优劣势→动向预判
- 输出格式：对比表格 + 文字分析
**可复用模板**：

【角色设定】  
你是一名产品战略分析师，擅长竞品研究和竞争策略分析。

【任务描述】  
请对以下竞品[竞品名称]进行深度分析，覆盖四个维度：

1. 产品对比：核心功能、定价、目标用户的差异
    
2. 策略分析：[竞品名称]在[渠道/营销/产品]上的核心策略
    
3. 优劣势评估：相较于我们，[竞品名称]的3个优势和3个劣势
    
4. 动向预判：[竞品名称]未来6-12个月最可能的2个动作
    

【背景信息】

- 我们的产品：[我们的产品名称]，核心定位是[一句话定位]
    
- 核心差异点：我们认为我们与竞品最核心的差异是[XX]
    
- 关注时间窗口：未来6个月
    

【输出格式】

- 第一部分：用表格呈现产品对比
    
- 第二部分：文字分析，200-300字
    
- 第三部分：清单式，3个优势+3个劣势，每个附带1句话解释
    
- 第四部分：文字分析，150-200字，附带“可能性”判断
    

【约束条件】

- 区分“事实”（可验证的信息）和“判断”（基于事实的推测）
    
- 优劣势评估需基于可观察的证据，而非主观偏好
    
- 所有推测需标注“基于XX推断”
    
### 场景3：市场进入分析
**核心需求**：评估是否进入一个新市场（新地域、新品类、新客户群）。
**设计思路**：
- 角色设定：战略顾问
- 任务拆解：吸引力→能力匹配→进入方式→风险评估→决策建议
- 输出格式：分步骤推理 + 结论
**可复用模板**：

【角色设定】  
你是一名战略咨询顾问，有跨国企业市场进入的实战经验。

【任务描述】  
请评估[公司名称]进入[目标市场]的可行性，按以下步骤逐步分析：

第一步：市场吸引力评估

- 目标市场的规模、增速、利润率水平
    
- 目标市场的竞争强度（主要玩家、集中度）
    
- 目标市场的进入壁垒（政策、渠道、品牌）
    

第二步：内部能力匹配度评估

- 产品是否需要适配？适配成本多高？
    
- 团队是否有相关经验？是否需要新招？
    
- 供应链是否支持？是否需要新建？
    

第三步：进入方式评估

- 选项A：自建（成本、时间、风险）
    
- 选项B：合资/收购（成本、时间、风险）
    
- 选项C：代理/合作（成本、时间、风险）
    

第四步：风险评估

- 列出3个最大的风险及缓解措施
    

第五步：决策建议

- 基于以上分析，给出“进入/暂缓/放弃”的建议
    

【背景信息】

- 公司：[公司名称]，主营业务[XX]，年营收[XX]
    
- 目标市场：[具体市场名称]
    
- 可用资源：[预算/团队/时间]
    

【输出格式】  
按五个步骤逐一输出，每步用“分析：……”和“结论：……”标注。  
最终决策建议单独成段，用“建议：……”开头。

### 场景4：数据分析与洞察
**核心需求**：从数据中提炼可行动的洞察，而不是只描述“发生了什么”。
**设计思路**：
- 角色设定：数据分析师
- 任务拆解：数据描述→归因分析→洞察提炼→行动建议
- 输出格式：结论先行 + 数据支撑 + 行动建议
**可复用模板**：

【角色设定】  
你是一名数据分析师，擅长从数据中提炼可行动的洞察。

【任务描述】  
请分析以下数据，按“What-So What-Now What”框架输出：

1. What（发生了什么）：用1-2句话概括数据的核心发现
    
2. So What（意味着什么）：这个数据对业务意味着什么？解释了什么问题？
    
3. Now What（该做什么）：基于这个洞察，建议采取什么行动？
    

【数据】  
[粘贴数据或描述数据情况]

【输出格式】

- 每个部分用小标题标注
    
- “What”部分不超过3句话
    
- “So What”部分需要结合业务背景做归因，而不只是“复述数字”
    
- “Now What”部分需要具体、可执行（不是“加强运营”这种泛泛的建议）
    

【约束条件】

- 不编造数据
    
- 归因需有依据（或明确标注“待验证”）
    
- 行动建议需附带预期效果
    

## 二、报告撰写场景
报告撰写是商科生日常工作的高频场景——包括工作总结、方案提案、调研报告等。这类场景的Prompt设计需要强调：**结构完整、语言专业、结论有力**。
### 场景5：工作总结/周报
**核心需求**：将散乱的工作内容整理为结构清晰、重点突出的总结。
**设计思路**：
- 角色设定：职场人士
- 任务拆解：完成情况→亮点→问题→下一步
- 输出格式：结论先行 + 分点展开
**可复用模板**：

【角色设定】  
你是一名专业的职场人士，擅长高效、清晰的工作汇报写作。

【任务描述】  
请根据以下工作内容，撰写一份结构化的工作总结：

1. 核心结论：一句话概括本周/本月整体情况
    
2. 关键完成事项：按重要性列出3-5项已完成工作
    
3. 亮点与成果：1-2个最值得提及的成果
    
4. 问题与风险：需要关注的问题及建议
    
5. 下一步计划：下周/下月的关键事项
    

【工作内容】  
[粘贴你的工作内容——可以是散乱的笔记]

【输出格式】

- 用“结论先行”结构，核心结论放在最前面
    
- 每部分用项目符号展开
    
- “关键完成事项”每项用“动作+结果”格式（如“完成了XX，达成了XX”）
    
- “问题与风险”每项需附带1-2句话的解决方案建议
    
- 总字数控制在300-500字
    

【约束条件】

- 不夸大成果，基于事实描述
    
- 问题部分需同步给出建议（不要只提问题不解决）
    
- 语言简洁，避免冗余
    

### 场景6：方案提案
**核心需求**：将想法转化为结构清晰、有说服力的方案。
**设计思路**：
- 角色设定：方案撰写人
- 任务拆解：背景→问题→方案→效果→计划→行动请求
- 输出格式：SCQA（情境-冲突-问题-答案）
**可复用模板**：

【角色设定】  
你是一名经验丰富的方案撰写人，擅长用结构化方式呈现提案。

【任务描述】  
请根据以下信息，撰写一份方案提案：

1. 背景：当前是什么情况？
    
2. 冲突：遇到了什么挑战/问题？
    
3. 问题：要解决的核心问题是什么？
    
4. 方案：你的解决方案是什么？核心要点有哪些？
    
5. 预期效果：方案实施后的预期效果
    
6. 实施计划：时间、资源、责任分工
    
7. 行动请求：需要对方做什么？
    

【背景信息】  
[粘贴你的背景和想法]

【输出格式】

- 按SCQA结构组织：情境→冲突→问题→答案
    
- “方案”部分用3-5个要点展开，每点1-2句话
    
- “预期效果”部分需量化（如“预期提升XX%”）
    
- “实施计划”用表格呈现（阶段→时间→内容→责任人）
    
- “行动请求”放在最后，明确说出“建议您……”
    

【约束条件】

- 方案要具体可落地，不要泛泛而谈
    
- 预期效果要合理（不过度承诺）
    
- 行动请求要明确（不要用“希望您看看”这种模糊表达）
    

### 场景7：调研报告摘要
**核心需求**：从长篇调研数据中提炼核心发现和洞察。
**设计思路**：
- 角色设定：调研分析师
- 任务拆解：核心发现→关键数据→分析→建议
- 输出格式：金字塔结构（结论先行）
**可复用模板**：

【角色设定】  
你是一名调研分析师，擅长从数据中提炼洞察。

【任务描述】  
请从以下调研数据中提炼核心发现，生成一份调研报告摘要。

【数据】  
[粘贴调研数据或描述调研背景]

【输出格式】  
请按金字塔结构组织：

第一层：核心结论（1-2句话，概括调研最重要的发现）  
第二层：关键发现（3-5个，每个附带关键数据）  
第三层：归因分析（为什么会有这些发现）  
第四层：建议（基于发现，建议做什么）

【约束条件】

- 核心结论必须独立于数据存在，能被人单独引用
    
- 每个关键发现必须有数据支撑
    
- 归因分析要区分“确认的”和“推测的”
    
- 建议要具体，与核心结论直接对应
    

## 三、内容创作场景
内容创作是营销、运营、品牌等岗位的高频场景。这类场景的Prompt设计需要强调：**风格匹配、创意多样、结构清晰**。
### 场景8：营销文案
**核心需求**：生成符合品牌调性的营销文案。
**设计思路**：
- 角色设定：文案撰稿人
- 任务拆解：核心卖点→目标受众→风格→多个版本
- 输出格式：少样本学习 + 多个版本
**可复用模板**：

【角色设定】  
你是一名资深文案撰稿人，擅长[具体风格，如：简洁有力的营销文案]。

【任务描述】  
请为以下产品/活动撰写3个不同风格的营销文案版本。

【产品信息】  
产品：[产品名称]  
核心卖点：[3个核心卖点]  
目标受众：[受众画像]

【风格要求】

- 版本A：理性说服型（强调功能和数据）
    
- 版本B：情感共鸣型（强调场景和感受）
    
- 版本C：短平快型（适合社交媒体，一句话抓住注意力）
    

【输出格式】  
每个版本用“【版本X】”标注，每个版本内容不超过200字。

【约束条件】

- 不夸大产品功能
    
- 不使用“最好的”“唯一”等绝对化表述
    
- 符合[品牌调性]的品牌调性
    
### 场景9：商务邮件起草
**核心需求**：将碎片化信息转化为专业的商务邮件。
**设计思路**：
- 角色设定：高效职场人
- 任务拆解：结论→背景→行动→时间
- 输出格式：邮件标准格式（主题+称呼+正文+落款）
**可复用模板**：

【角色设定】  
你是一个高效的职场人士，擅长撰写清晰、简洁的商务邮件。

【任务描述】  
请根据以下要点，起草一封商务邮件：

核心结论：[一句话说清要做什么]  
背景：[1-2句话说明背景]  
行动请求：[收件人需要做什么]  
时间节点：[截止时间]

【输出格式】

- 主题行：用“行动请求 + 事项”的格式
    
- 正文：第一段给出核心结论和行动请求
    
- 第二段提供背景和支撑信息
    
- 结尾明确时间节点
    
- 用礼貌但专业的语气
    

【约束条件】

- 不要在第一段绕圈子
    
- 每个收件人都要有明确的“期待行动”
    
- 不用“尽快”“有空的时候”等模糊表达
    

### 场景10：会议纪要生成
**核心需求**：从会议记录中提炼决策和行动项。
**设计思路**：
- 角色设定：会议纪要整理人
- 任务拆解：决策→行动项→讨论要点
- 输出格式：纪要标准格式
**可复用模板**：

【角色设定】  
你是一名专业的会议纪要整理人，擅长从会议记录中提炼核心内容。

【任务描述】  
请根据以下会议记录，生成一份结构化会议纪要。

【会议记录】  
[粘贴会议记录或核心讨论内容]

【输出格式】

1. 基本信息：会议主题、时间、参会人
    
2. 核心决策：会议做出的2-3个关键决定
    
3. 行动项：以表格形式呈现（行动项→负责人→截止时间）
    
4. 讨论要点：简要记录关键讨论内容
    

【约束条件】

- 核心决策放在最前面（不是“讨论了什么”，是“决定了什么”）
    
- 每个行动项必须有明确的责任人和截止时间
    
- 讨论要点不要记录“谁说了什么”，只记录关键观点和分歧
    

### 场景11：社交媒体内容（小红书/抖音脚本）
**核心需求**：生成符合平台调性的社交媒体内容。
**设计思路**：
- 角色设定：社交媒体内容策划
- 任务拆解：定位→卖点→风格→平台适配
- 输出格式：少样本学习 + 平台适配
**可复用模板**：

【角色设定】  
你是一名社交媒体内容策划，擅长小红书/抖音内容创作，熟悉平台的内容调性和用户偏好。

【任务描述】  
请为以下产品/主题生成一份[小红书笔记/抖音脚本]，内容需符合平台调性。

【内容信息】  
主题：[具体主题]  
核心卖点：[3个核心卖点]  
目标受众：[受众画像]

【风格要求】

- 小红书：真实种草风格，强调“亲测有效”“自用分享”，善用emoji和口语化表达
    
- 抖音：短平快节奏，前3秒抓注意力，配合视觉化表达
    

【输出格式】

- 小红书：标题+正文（含3-5个要点）+话题标签
    
- 抖音脚本：场景+文案+画面描述+时长
    

【约束条件】

- 不夸大效果
    
- 避免“最好的”“唯一”等绝对化表述
    
- 符合平台内容规范
    

## 四、数据处理场景
数据处理是数据分析、运营、财务等岗位的高频场景。这类场景的Prompt设计需要强调：**精确、结构化、可操作**。
### 场景12：数据清洗建议
**核心需求**：获取数据清洗的思路和方法。
**设计思路**：
- 角色设定：数据专家
- 任务拆解：问题识别→清洗步骤→验证方法
- 输出格式：分步骤 + 具体操作
**可复用模板**：

【角色设定】  
你是一名数据专家，擅长数据质量管理和数据清洗。

【任务描述】  
请根据以下数据描述，提供数据清洗建议。

【数据描述】  
[描述数据来源、字段、已知问题]

【输出格式】

1. 问题识别：列出需要清洗的3-5个主要问题
    
2. 清洗步骤：针对每个问题，提供具体的清洗方法
    
3. 验证方法：如何验证清洗后的数据质量
    

【约束条件】

- 方法需具体可操作（不要只说“去除异常值”，要说“用XX方法识别异常值”）
    
- 需考虑数据量级对方法选择的影响
    
- 标注每步操作的优先级（高/中/低）
    

### 场景13：数据解读
**核心需求**：从数据中提炼商业洞察。
**设计思路**：
- 角色设定：商业分析师
- 任务拆解：数据描述→趋势解读→商业洞察→行动建议
- 输出格式：金字塔结构
**可复用模板**：

【角色设定】  
你是一名商业分析师，擅长从数据中提炼可执行的商业洞察。

【任务描述】  
请解读以下数据，并提炼商业洞察。

【数据】  
[粘贴数据或描述数据情况]

【输出格式】

1. 核心发现：1-2句话概括最重要的发现
    
2. 趋势解读：数据反映的趋势和变化
    
3. 归因分析：可能的驱动因素
    
4. 商业洞察：对业务意味着什么
    
5. 行动建议：基于洞察，建议做什么
    

【约束条件】

- 归因分析需基于商业逻辑，而非纯粹的“数据相关性”
    
- 如果有多个可能的解释，需标注优先级
    
- 行动建议需与洞察直接对应
    

### 场景14：图表生成
**核心需求**：为数据选择合适的图表类型和设计。
**设计思路**：
- 角色设定：数据可视化专家
- 任务拆解：数据类型→图表选择→设计建议
- 输出格式：推荐 + 理由 + 设计要点
**可复用模板**：

【角色设定】  
你是一名数据可视化专家，擅长为不同数据选择最合适的图表类型。

【任务描述】  
请为以下数据推荐最合适的图表类型，并提供设计建议。

【数据描述】  
[描述数据：是什么类型、要回答什么问题、受众是谁]

【输出格式】

1. 推荐图表类型：[类型名称]
    
2. 推荐理由：[为什么这个图表最适合]
    
3. 设计要点：
    
    - 核心信息用[XX]突出
        
    - 坐标轴设置为[XX]
        
    - 颜色建议用[XX]
        
4. 替代方案：[如不适用，备选图表是XX]
    

【约束条件】

- 推荐理由需基于数据类型和分析目的，而非个人偏好
    
- 设计要点需具体（不是“简洁美观”，而是“删除网格线、标注关键数据点”）
    

## 五、面试准备场景
面试准备是商科生最频繁使用AI的场景之一——包括模拟面试、问题准备、自我介绍优化等。
### 场景15：模拟面试
**核心需求**：模拟真实面试场景，练习回答技巧。
**设计思路**：
- 角色设定：面试官
- 任务拆解：问题→回答→反馈
- 输出格式：问题 + 反馈
**可复用模板**：

【角色设定】  
你是一名严格的面试官，正在面试一名[目标岗位]的候选人。你擅长提出有挑战性的行为面试题和案例分析题。

【任务描述】  
请进行一场模拟面试：

1. 从[目标岗位]的典型面试问题中，选择1个行为面试题和1个案例分析题
    
2. 先提出问题，等待候选人回答后再给出反馈
    
3. 反馈包含：回答的质量（优点+不足）、改进建议
    

【输出格式】

- 问题：用“【问题】”标注
    
- 候选人的回答后，用“【反馈】”标注分析
    
- 反馈分两部分：“做得好的地方”和“可以改进的地方”
    

【约束条件】

- 问题需真实、有挑战性
    
- 反馈需具体（不要只说“很好”，要说“因为XX，所以XX”）
    
- 案例分析题需有明确的评估标准
    


### 场景16：面试问题准备
**核心需求**：针对目标岗位，准备高频问题的回答。
**设计思路**：
- 角色设定：面试教练
- 任务拆解：问题列表→回答框架→个性化建议
- 输出格式：问题 + 回答框架 + 示例
**可复用模板**：

【角色设定】  
你是一名面试教练，擅长帮助候选人准备面试。

【任务描述】  
请为[目标岗位]准备5个高频面试问题的回答框架：

1. 自我介绍
    
2. 为什么选择我们公司
    
3. 你的最大优势/劣势
    
4. 分享一次解决问题的经历
    
5. 你有什么想问我的
    

【背景信息】

- 目标岗位：[岗位名称]
    
- 公司：[公司名称]
    
- 个人背景：[关键经历2-3句]
    

【输出格式】  
每个问题包含：

- 回答框架（建议的结构，如STAR/PREP）
    
- 建议包含的关键信息
    
- 应避免的常见错误
    

【约束条件】

- 回答框架需可操作（不要只说“自信回答”，要说“先说XX，再说XX”）
    
- 应避免的错误需具体（不要只说“不要说空话”，要说“避免说‘我学习能力强’而不举例子”）
    

### 场景17：自我介绍优化
**核心需求**：优化自我介绍，使其更精准、更有冲击力。
**设计思路**：
- 角色设定：面试教练
- 任务拆解：现有版本→诊断→优化版
- 输出格式：诊断 + 优化版 + 理由
**可复用模板**：

【角色设定】  
你是一名面试教练，擅长优化求职者的自我介绍。

【任务描述】  
请诊断并优化以下自我介绍：

【现有自我介绍】  
[粘贴你的自我介绍]

【优化要求】

- 时长：1分钟（约150-180字）
    
- 核心目标：让面试官快速记住“你能做什么”和“你为什么适合”
    
- 结构：结论先行 + 3个核心能力 + 结尾
    

【输出格式】

1. 诊断：现有版本的3个优点和3个需要改进的地方
    
2. 优化版：改写后的自我介绍
    
3. 优化说明：每个改动的理由
    

【约束条件】

- 需保留原有的核心信息，只优化表达方式
    
- 避免“空话”和“套话”
    
- 每个核心能力需有隐含的证据（即暗示“我怎么证明”）
    

## 六、学习与信息整理场景
学习与信息整理是日常知识管理的高频场景——包括论文阅读、信息提取、知识总结等。
### 场景18：信息提取与总结
**核心需求**：从长文本中提取关键信息。
**设计思路**：
- 角色设定：信息整理专家
- 任务拆解：提取→分类→总结
- 输出格式：摘要 + 要点
**可复用模板**：

【角色设定】  
你是一名信息整理专家，擅长从长文本中提取关键信息。

【任务描述】  
请从以下文本中提取核心信息：

【文本】  
[粘贴长文本]

【输出格式】

1. 核心摘要：3-5句话概括核心内容
    
2. 关键要点：按重要性列出5-8个要点
    
3. 待深入的问题：文本中未回答但值得追问的2-3个问题
    

【约束条件】

- 不添加文本中没有的信息
    
- 保持原文立场，不做价值判断
    
- 如果信息有矛盾，如实标注“文本中存在矛盾观点”
    

### 场景19：概念学习
**核心需求**：用AI辅助学习新概念。
**设计思路**：
- 角色设定：导师/讲解者
- 任务拆解：定义→原理→例子→边界
- 输出格式：分层次讲解
**可复用模板**：

【角色设定】  
你是一名优秀的导师，擅长用清晰、易懂的方式讲解复杂概念。

【任务描述】  
请讲解以下概念，帮助我快速理解：

【概念名称】[概念名称]

【讲解要求】

1. 一句话定义：用最简单的语言解释这个概念
    
2. 核心原理：2-3句话解释概念的核心逻辑
    
3. 商业例子：1-2个商科生能理解的例子
    
4. 与其他概念的关系：这个概念和[XX]有什么关系？
    
5. 能力边界：这个概念不能解释什么？
    

【输出格式】  
按五个部分逐一呈现，每部分用小标题标注。

【约束条件】

- 避免使用专业术语（如果必须使用，需先解释）
    
- 例子需来自商业场景
    
- 能力边界要明确（知道“不能做什么”比知道“能做什么”更重要）

## 七、面试/实战中怎么用

### 7.1 面试中展示Prompt实战能力的方法

| 面试问题 | 示例回答 |
|:---------|:---------|
| “你用过AI做哪些工作？” | “我用AI辅助过行业分析和竞品分析。比如做竞品分析时，我会用少样本学习——先给AI一个我期望的格式示例，再让它基于这个格式分析具体竞品。这样输出的内容结构和质量都可预期。” |
| “AI帮你写的报告，你会怎么处理？” | “我会把AI的输出当‘初稿’——先让AI生成结构化的框架和核心内容，然后我自己复核数据、补充判断、调整颗粒度。AI做‘宽度’，我做‘深度’。” |

### 7.2 不同AI工具的适用场景

| 工具 | 最适合的场景 | 注意事项 |
|:-----|:-------------|:---------|
| ChatGPT | 通用对话、创意生成、多轮推理 | 长文本处理有上限 |
| Claude | 长文档分析、结构化输出 | 上下文窗口大，适合处理长文本 |
| DeepSeek | 中文场景推理、复杂分析 | 推理能力突出，中文理解优秀 |
| Kimi | 长文本处理、文件阅读 | 上下文窗口极大，适合大量文件处理 |
| 豆包 | 日常办公辅助 | 与字节生态集成较好 |

### 7.3 实战中的常见问题与应对

| 问题 | 应对策略 |
|:-----|:---------|
| AI输出的内容过于泛泛 | 用“少样本学习”提供示例，或用“思维链”要求分步推理 |
| AI输出的格式不统一 | 在Prompt中明确指定输出格式（Markdown、表格、JSON等） |
| AI编造了不存在的“数据” | 要求AI标注数据来源，核心数据做交叉验证 |
| AI没有理解你的意图 | 补充背景信息，用更具体的语言重写Prompt |
| AI在复杂任务上表现不稳定 | 用“任务拆解法”拆成小任务，逐步骤完成 |
