# VIA 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位
VIA 是一款面向商学院本科生的成就可视化平台，以"游戏化收集成就"为核心体验，帮助学生记录、整理、展示在校荣誉与课外经历，增强自我价值感，并为未来求职预留 AI 简历增值空间。

### 1.2 目标用户
- **首期**：商学院本科生（会计、金融、市场营销、管理等专业）
- **年级**：大一至大四，用户自选年级
- **拓展性**：架构支持按专业大类、年级阶段（实习/就业）扩展

### 1.3 核心价值
- 成就收集如游戏，获得即时反馈与视觉满足
- 多维度可视化展示（时间轴、雷达图、汇总看板）
- 一键导出成就档案 PDF
- 全链路自填自管，零门槛上手

## 5. 数据与存储

### 5.1 存储方案
- **MVP 阶段**：纯前端 LocalStorage，无需后端
- **数据结构**：JSON 格式，支持导出/导入
- **自动保存**：录入时自动保存，防丢失

### 5.2 数据导出
| 格式 | 内容 | 用途 |
|------|------|------|
| JSON | 完整数据 | 备份、迁移、恢复 |
| PDF | 成就档案 | 求职附件、存档 |

**PDF 模板**：多页档案式，含封面、时间轴、汇总表、详情页

### 5.3 批量录入
- 支持粘贴表格文本自动解析
- 预留 Excel 导入接口（CSV 格式）

## 6. 交互与体验

### 6.1 全局交互
| 功能 | 实现 |
|------|------|
| 搜索 | `Ctrl/Cmd + K` 全局搜索，支持名称/类型/标签/时间 |
| 新建 | `N` 快捷键唤起录入 |
| 侧栏 | 窄屏自动折叠，汉堡菜单触发 |
| 主题 | 系统跟随 / 强制深色 / 强制浅色 |

### 6.2 动画反馈
- 成就提交：徽章弹出 + 粒子爆发 + 指数滚动
- 获得新等级：全屏遮罩庆祝动画
- 页面切换：平滑过渡，无闪烁
- 加载状态：骨架屏，禁止生硬白屏

### 6.3 空状态
- 首次访问：演示模式，展示示例数据
- 清空数据：引导录入第一步成就
- 筛选无结果：提示调整条件
