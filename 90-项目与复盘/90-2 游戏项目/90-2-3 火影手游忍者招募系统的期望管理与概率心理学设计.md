## 分析层

### 数学模型：高招S忍获取的期望与方差

**基础概率模型**（简化版，用于理解）：

假设：
- 每抽成本：168金币
- S碎片概率：p = 0.115（11.5%）
- 10连保底：每10抽至少1片S
- 目标：100片S忍

**纯概率期望（无首付、无返利）**：
$$E[抽数] = \frac{100}{p} = \frac{100}{0.115} \approx 867抽$$

显然这不现实，说明**首付返利和保底机制是系统的核心**，不能忽略。

**含保底的修正模型**：
10连保底意味着每10抽至少1片，即：
- 前9抽按概率出（期望9×0.115=1.035片）
- 第10抽保底1片
- 每10连期望碎片：~2.0片
- 每50抽保底5片：~3.0片
- 理论期望抽数：~334抽（符合预期与社区评论）

**结论**：纯抽卡不出S整卡，碎片系统+首付返利才是主要来源。火影的S忍获取**不是"抽出来"的，而是"攒出来"的**。

### 模拟前提与参数设定
#### 1. 玩家V等级分布假设（正态分布拟合）

为了还原真实付费玩家群体的V等级结构，模拟中对月卡党与R党采用**正态分布（Normal Distribution）**进行拟合，而非固定单一档位：

- **月卡党（小额付费）**：V等级区间设定为 **V5 - V15**，分布服从 **X ~ N(9, 2.5²)**（均值V9，标准差2.5）。该设定模拟了月卡玩家在持续续费过程中，因活动充值、忍法帖等小额补差行为导致的V等级自然分化，主力群体集中在V5-V10区间。
    
- **R党（中高付费/648礼包党）**：V等级区间设定为 **V10 - V15**，分布服从 **X ~ N(13, 1.8²)**（均值V13，标准差1.8）。该设定模拟了核心付费玩家通过常规充值维持较高V等级的状态。
    
- **0氪与淡游党**：固定为 **V0 - V4** 档位，不引入正态分布，以符合其“无稳定付费行为”的特征。
#### 2. 招募核心机制前提（游戏底层规则）

模拟严格遵循游戏内实测逻辑，确保期望值收敛于理论值：

- **双保底叠加机制**：
    
    - **10抽保底**：每10抽为一个检查窗口，若该窗口内自然掉落+补足碎片总数<1，则在窗口末端补足至1片。
        
    - **50抽保底**：每50抽为一个独立检查窗口，若该窗口内总碎片数<5，则补足至5片。
        
    - _关键逻辑_：**两种保底独立计算且产出叠加**。纯保底效率为每10抽固定产出2片（即10抽保底1片 + 50抽保底均摊1片）。
        
- **基础概率**：单抽S忍碎片自然掉落概率恒定为 **11.5%**。
    
- **首付返利规则**：仅在高招上架**首月**生效，严格按照V等级档位表（V0-V4/V5-V9/V10-V14/V15）发放累计抽数返利。
    

#### 3. 玩家资源与行为前提（时间货币模型）

为将抽数转化为时间维度（月份），做出以下经济行为假设：

- **收入全量转化**：玩家每月获得的全部金币（含月卡、决斗场、日常活跃）均视为**定向投入当期高招**，不存在金币外流（如购买体力、饰品等）。
    
- **玩家月收入基准**（单位：金币）：
    
    - **纯免费**：12,000/月（约71抽）
        
    - **月卡党 / R党**：16,722/月（约99抽，含月卡及充值额外赠送的金币）
        
    - **淡游/新手**：8,400/月（约50抽，模拟无法完成全勤任务的状态）
        
- **648礼包前置**：R党（648礼包档）在首月抽取前，默认已购买当期648元30片S忍碎片礼包，碎片直接计入背包。
    

#### 4. 模拟执行参数

- **蒙特卡洛次数**：每组玩家类型独立运行 **10,000次** 独立随机模拟。
    
- **截断条件**：当玩家累计S忍碎片达到 **100片** 时，立即停止模拟并记录当前总抽数；若超过 **24个月** 仍未集齐，视为失败并排除异常极值（本模拟中完成率均为100%）。
    
- **置信区间**：报告指标取平均值、中位数及 **90%分位数**（用以衡量非酋玩家的体验下限）。

### 关键洞察

### 一、结构性问题：长周期机制对“局外人”的排斥

火影高招系统本质上是一个**“持续活跃者友好型”**系统，而非“全玩家友好型”系统。

| 玩家类型      | 获取周期       | 能否在卡池期内完成？           | 能否进入“隔期抽取”循环？ |
| --------- | ---------- | -------------------- | ------------- |
| 纯免费       | 3.48个月     | ✅ 能（卡池4个月）           | ✅ 能           |
| 月卡党       | 2.33个月     | ✅ 能                  | ✅ 能           |
| R党(648礼包) | 1.24个月     | ✅ 能                  | ✅ 能           |
| 淡游/新手     | **4.94个月** | ❌ **不能**（超出卡池0.94个月） | ❌ **不能**      |

> **核心矛盾**：一个S忍在高级招募中仅存在 **4个月**（然后下架进入特权商店）。月卡党（2.33月）和纯免费（3.48月）都能在卡池期内完成收集，进入“A忍上架时抽S忍”的隔期循环。但淡游/新手需要 **4.94个月**——超出卡池窗口近1个月，意味着他们**永远无法在卡池期间完成任何一个S忍**，始终处于“上期忍者还没出，下期忍者已上架”的追赶状态。

**这是系统对淡游/新手最隐蔽也最残酷的结构性排斥。**

### 二、付费价值锚点：R党的“时间压缩”感知极强

|对比组|抽数差|月份差|
|---|---|---|
|纯免费 → 月卡党|-16抽（-6.7%）|-1.15个月（-33%）|
|月卡党 → R党(648礼包)|**-108抽（-47%）**|**-1.09个月（-47%）**|

- **月卡的价值** = **时间压缩**（3.5月→2.3月，提前1个月），但抽数上几乎没省。
    
- **648礼包的价值** = **抽数+时间双重压缩**（2.3月→1.2月，省108抽），感知极强。

> **策划启示**：648礼包的30片碎片在数值上等价于 **~108抽的期望产出**，是游戏中“付费换时间”最清晰的锚点。当前定价策略有效，建议维持。

### 三、月卡党的“感知价值危机”

月卡党相比纯免费玩家：

- 每月多花50元（月卡）
    
- 每月多出约4,722金币（约28抽）
    
- 但最终仅比纯免费少抽 **16抽**（省1.15个月）

> **问题**：月卡党的核心价值是“提前1个月拿到忍者”，这在决策层（策划）看来是合理的“时间货币”兑换，但在玩家感知层——“我花了钱，抽数居然和0氪差不多”——这是一个**感知价值错位**。建议在月卡权益中增加送少量高招券显性权益，强化付费感知。
### 四、淡游/新手的“5个月魔咒”

淡游/新手玩家：

- 平均抽数 **246.9抽**（与纯免费几乎一样）
    
- 但需要 **4.94个月** 才能攒够
    
- 而卡池周期仅 **4个月**
    

> **后果**：淡游/新手永远在“补上一期”的S忍，永远无法参与“本期新S忍”的强度环境和社区讨论。这种“永远慢一拍”的体验，是退游的核心推手。

### 五、结论：三句话总结

1. **对活跃玩家（纯免费/月卡/R党）**：系统运转良好，时间→忍者的兑换路径清晰可预期。
    
2. **对月卡党**：价值感存在“隐忧”——建议通过小额高频权益强化付费感知。
    
3. **对淡游/新手**：系统存在**结构性排斥**——4个月卡池周期与5个月获取周期之间的1个月缺口，是流失的关键拐点。

## 方案层：基于模拟数据的系统优化设计

### 设计原则

基于模拟结果的四个核心发现，提出 **“进得来、留得住、回得来”** 三原则：

|原则|针对玩家类型|核心目标|
|---|---|---|
|**进得来**|新手|降低认知门槛，3个月内完成首个S忍|
|**留得住**|月卡党 / 纯免费|强化月卡感知价值，维持活跃循环|
|**回得来**|淡游玩家|将获取周期从4.94个月压缩至<4个月，纳入卡池周期|

### 方案1：新手/回归“补给周期”机制

**问题**：淡游/新手月收入仅8,400金币（50抽/月），需4.94个月才能攒出一个S忍，超出卡池4个月周期0.94个月，**永远无法在卡池期内完成收集**【模拟数据】。

**设计**：

- **触发条件**：账号注册时间≤60天，或连续14天未登录后回归
    
- **触发效果（持续一个高招周期）** ：
    
    - 首次S忍首付抽数从100抽降至 **70抽**（返利仍按V0的100抽档位发放，即25片）
        
    - 月收入不变（8400金币），但碎片缺口被补给覆盖


**数学验证**：

| 项目          | 优化前（淡游/新手）                | 优化后                              |
| ----------- | ------------------------- | -------------------------------- |
| 月收入         | 8,400金币（50抽）              | 8,400金币（50抽）                     |
| 首付返利        | 25片                       | 25片                              |
| 补缺口所需抽数     | 31 ÷ 0.2 ≈ 155抽           | 31 ÷ 0.2 ≈ 155抽（同上）              |
| **但首付抽数降低** | 需先抽100抽拿返利                | 抽70抽就拿满25片返利                     |
| **总抽数估算**   | ~247抽                     | **~220抽**（70首付 + 150补缺口）         |
| **所需月份**    | 247 ÷ 50 = **4.94个月**     | 220 ÷ 50 = **4.4个月**（仍略超4个月）     |

> ⚠️ 仅靠补给仍不够，需配合方案B的 **“金币产出补强”** 。

**调整设计**：回归/新手60天内，每周提供300金币限时活动，月收入提升至 8,400 + 1,200 = **9,600金币**（约57抽/月）。

| 项目       | 优化后                            |
| -------- | ------------------------------ |
| 月收入      | 9,600金币（57抽/月）                 |
| 总抽数估算    | ~220抽                          |
| **所需月份** | 220 ÷ 57 = **3.86个月 ✅ 进入卡池周期** |

**预期效果**：

- 新手/回归玩家首次S忍获取周期从 **4.94个月降至3.86个月**，纳入4个月卡池窗口
    
- 60日留存率预估提升 **10-15%**
    
- 回归玩家付费转化率提升 **8-12%**（重建目标感）

### 方案2：月卡党“感知价值强化”UI

**问题**：模拟显示，月卡党相比纯免费玩家，平均抽数仅少16抽（-6.7%），但平均月份少1.15个月（-33%）。**月卡的真实价值是“时间压缩”而非“抽数压缩”**，但当前UI只展示抽卡结果，玩家感知不到“提前了1个月”的价值。

**设计**：

在高招主界面增加 **“时间价值显示”** 模块：

|UI元素|展示内容|
|---|---|
|**进度罗盘**|显示当前碎片数 / 100片，以及 **“预计还需X天”**|
|**月卡加速对比**|显示“如果未开通月卡，预计还需X天。月卡已为您加速 **X天**。”|
|**获取日历**|日历视图，标注“预计获得日期”，强化目标感|

**示例文案**：

> “您当前已收集47片S忍碎片，预计还需 **42天** 完成。月卡已为您加速 **18天**，感谢您的支持！”

**心理学原理**：

- 将抽象的“概率”转化为具体的“进度”（Progress Principle）
    
- 通过对比突出月卡的“时间压缩”价值（Anchoring Effect）
    
- 将“花了钱但没少抽”的负面感知，转化为“提前了18天拿到”的正面感知

**成本**：纯UI改动，无数值调整，开发成本低，风险极低。

最后补充，考虑到火影忍者手游的受众群体较为单一，，决斗场等环境较难适应，新手进入门槛较高，目前仍需把重点放在永续稳定运营，进行老玩家维护、机制创新、体系平衡，拉新所占比重不应太高，以上均受游戏自身特点影响
