# Week 2 — Exercises

Three guided exercises, ~45–90 min each. Write every rewrite, every survey item, and every SQL row yourself — don't skim the lectures and skip straight to the answer key. Research judgment is built by doing the rewrite badly first, then correctly, not by reading someone else's correct version.

1. **[Exercise 1 — Rewrite Leading Interview Questions](exercise-01-rewrite-leading-questions.md)** — take 10 real leading questions and rewrite each to pass the Mom Test. *(~45 min.)*
2. **[Exercise 2 — Design an Unbiased Survey](exercise-02-design-an-unbiased-survey.md)** — write a 10-item survey for Shiftly and back it with a SQL schema. *(~60 min.)*
3. **[Exercise 3 — Affinity-Map an Interview Transcript](exercise-03-affinity-map-a-transcript.md)** — turn a raw, uncoded transcript into SQL rows, code them into themes, and query the result. *(~75–90 min.)*

## Before you start

- You've completed all three lectures.
- You ran the seed from the [week README](26-product%20learning（附）/curriculum/week-02-user-research-and-discovery/README.md) and `SELECT COUNT(*) FROM participants;` returns **15**.
- You have a shell open: `psql shiftly_research` (Postgres) or `sqlite3 shiftly_research.db` (SQLite).

## Suggested workflow

- Open the exercise file beside your notes app or terminal.
- For Exercise 1 and 2, draft your first attempt, then re-read the "why it's leading" or "why it's biased" checklist before revising — most first drafts fail at least one rule, and noticing why is the actual lesson.
- For Exercise 3, resist the urge to code a quote before you've read the whole transcript once — themes should emerge from the full picture, not from reacting to the first striking line.
- Save your work as instructed at the end of each exercise. You'll commit it to your portfolio.
