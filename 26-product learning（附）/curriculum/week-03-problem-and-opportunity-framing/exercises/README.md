# Week 3 — Exercises

Three exercises, building in order: sorting your judgment (no data needed), sizing with real SQL, then structuring the whole thing into a tree. Do them in order — Exercise 3 assumes the sizing result from Exercise 2.

## How to work them

- Exercise 1 is a written sorting/classification task — no database needed, just the reasoning from Lecture 1.
- Exercise 2 needs the `signup_cohort` table from the [week README](26-product%20learning（附）/curriculum/week-03-problem-and-opportunity-framing/README.md#set-up-this-weeks-seed-dataset) — set it up before you start if you haven't already.
- Exercise 3 is a written/diagramming task that reuses your Exercise 2 numbers — keep that file open.
- Each exercise states a deliverable and an estimated time. Commit your answers to your portfolio as you go; don't wait until Sunday.
- There's no single "correct" answer key for Exercises 1 and 3 — judgment calls are expected and should be defended in writing, the same way the challenges work. Exercise 2 has concrete expected numbers because it's a SQL exercise — verify your query results against them.
