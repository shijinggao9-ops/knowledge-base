# 20-4-5 R语言入门与统计分析

**定位**：R是统计学家和数据科学家为统计分析而设计的语言——它在学术研究、生物统计、金融量化、市场研究等领域有深厚的积累。如果说Python是“通用数据分析工具”，R就是“统计分析的专用工具”。R的优势在于：统计建模的函数更直接、学术社区的包更专业、可视化（尤其是`ggplot2`）的表达力更强。这个文件帮助你在已有Python基础的前提下，理解R的独特价值、掌握R的基础语法和核心分析能力，让你在面对统计分析任务时能够选择合适的工具。

**适用场景**：学术研究中的统计分析、市场研究中的假设检验与回归分析、金融中的量化建模、需要专业统计图表输出的场景。


## 一、R vs Python：如何选择？

### 1.1 核心区别

| 维度 | Python | R |
|:-----|:-------|:---|
| **设计目标** | 通用编程语言 | 统计计算与数据可视化 |
| **学习曲线** | 平缓（语法直观）| 中等（有独特语法，如`<-`赋值）|
| **统计分析** | 需要额外库（`scipy.stats`、`statsmodels`）| 原生支持，函数直接可用 |
| **数据可视化** | Matplotlib/Seaborn（需要调参）| ggplot2（语法一致，精美默认）|
| **机器学习** | scikit-learn、TensorFlow、PyTorch生态强大 | 有，但生态不如Python |
| **学术社区** | 工业界、AI/ML领域为主 | 统计学、生物信息学、心理学等学术领域 |
| **数据操作** | Pandas（语法接近SQL思维）| dplyr（管道操作`%>%`，语法更专注数据操作）|
| **报告生成** | Jupyter Notebook | R Markdown（原生支持统计输出）|
| **IDE** | Jupyter、VS Code、PyCharm | RStudio（专为R设计，体验极佳）|

### 1.2 什么时候该用R？

| 场景 | 为什么用R |
|:-----|:----------|
| **学术论文中的统计分析** | 统计模型（回归、方差分析、生存分析等）的函数更直接，学术期刊的审稿人更熟悉R输出 |
| **复杂统计图表** | `ggplot2`的图层语法在表达统计图形时极为灵活，学术图表首选 |
| **市场研究/用户研究中的假设检验** | t检验、卡方检验、方差分析等一行代码即可完成，输出规范 |
| **金融时间序列分析** | 有专业的金融分析包（`quantmod`、`PerformanceAnalytics`）|
| **需要生成可重复的统计报告** | R Markdown可以嵌入代码、统计输出和文字，一键生成PDF/HTML报告 |

### 1.3 什么时候该用Python？

| 场景 | 为什么用Python |
|:-----|:---------------|
| **大规模数据处理（亿级数据）** | Python的Pandas + Dask / Spark生态更成熟 |
| **机器学习/深度学习项目** | scikit-learn、XGBoost、TensorFlow、PyTorch生态更丰富 |
| **生产环境部署** | Python的API部署（Flask/FastAPI）更成熟 |
| **自动化流程（爬虫、邮件、Excel）** | Python的通用编程能力更强 |

> **一句话建议**：如果你是商科生，**先学Python**（通用性更强），再根据需要补充R；如果你是统计学方向或学术研究为主，**R优先**。

#### 向量（Vector）

R中最基本的数据结构是向量——一组同类型元素的集合。向量是R的“原子单位”，几乎所有操作都围绕向量展开。

```R

# 创建向量
v1 <- c(1, 2, 3, 4, 5)           # c() = combine
v2 <- c("北京", "上海", "深圳")    # 字符向量
v3 <- 1:10                        # 1到10的整数序列
# 向量运算（向量化是其核心优势）
v1 + 10           # [11, 12, 13, 14, 15]
v1 * 2            # [2, 4, 6, 8, 10]
sum(v1)           # 15
mean(v1)          # 3
sd(v1)            # 标准差
# 向量索引（从1开始，与Python不同）
v1[1]             # 1（第一个元素）
v1[1:3]           # 1, 2, 3
v1[-2]            # 去掉第二个元素（1, 3, 4, 5）
```

#### 数据框（DataFrame）

数据框是R中最常用的二维表格结构，类似于Python的Pandas DataFrame。它的底层可以理解为“等长向量的列表”——每一列是一个向量，所有列的长度相同。

```R

# 创建数据框
df <- data.frame(
  客户 = c("张三", "李四", "王五"),
  城市 = c("北京", "上海", "北京"),
  销售额 = c(25000, 18000, 32000),
  订单数 = c(15, 12, 20)
)
# 查看数据
head(df)          # 前几行
str(df)           # 数据结构（类型、维度等）
summary(df)       # 统计摘要
dim(df)           # 行列数
```

#### 列表（List）

列表是R中最灵活的数据结构，可以包含不同类型、不同长度的元素，常用于存储复杂对象（如模型结果、多个数据框等）。

```R

# 创建列表
my_list <- list(
  name = "张三",
  age = 28,
  scores = c(85, 90, 88),
  address = list(city = "北京", street = "朝阳路")
)
# 访问列表元素
my_list$name      # "张三"
my_list[[2]]      # 28（按位置）
```

## 三、数据操作：tidyverse与dplyr

`tidyverse`是R中最流行的数据分析生态包集合，其中`dplyr`是数据操作的核心包。`dplyr`的语法比Pandas更接近“数据操作的思维”——用动词描述你想要对数据做什么。

### 3.1 管道操作符：%>%

在R中，`%>%`（管道操作符）用于将左侧的结果“传递”给右侧的函数作为第一个参数。它让数据操作的代码从“从内到外”变为“从左到右”——可读性大幅提升。

```R

library(dplyr)
# 传统写法（从内到外，难读）
arrange(filter(summarise(group_by(df, 城市), 总销售额 = sum(销售额)), 总销售额 > 50000), desc(总销售额))
# 管道写法（从左到右，易读）
df %>%
  group_by(城市) %>%
  summarise(总销售额 = sum(销售额)) %>%
  filter(总销售额 > 50000) %>%
  arrange(desc(总销售额))
```

### 3.2 dplyr核心函数

`dplyr`的核心动词共有5个，覆盖了绝大多数数据操作场景：`filter()`、`select()`、`mutate()`、`summarise()`、`arrange()`。加上`group_by()`配合`summarise()`进行分组聚合，覆盖了SQL中`SELECT ... WHERE ... GROUP BY ... ORDER BY`的完整操作链。

|函数|用途|类比|
|---|---|---|
|`filter()`|筛选行（满足条件的行）|SQL的`WHERE`|
|`select()`|选择列|SQL的`SELECT`部分|
|`mutate()`|创建新列 / 修改列|添加计算列|
|`summarise()`|汇总（聚合计算）|SQL的`GROUP BY + 聚合函数`|
|`arrange()`|排序|SQL的`ORDER BY`|
|`group_by()`|分组（配合`summarise()`使用）|SQL的`GROUP BY`|

```R

# 筛选：销售额大于20000的客户
df %>% filter(销售额 > 20000)
# 选择列：只保留客户和城市
df %>% select(客户, 城市)
# 创建新列：计算客单价（销售额/订单数）
df %>% mutate(客单价 = 销售额 / 订单数)
# 按城市分组汇总
df %>%
  group_by(城市) %>%
  summarise(
    总销售额 = sum(销售额),
    平均销售额 = mean(销售额),
    客户数 = n()           # n()是dplyr中的计数函数，统计当前组的行数
  )
# 排序
df %>% arrange(desc(销售额))   # 销售额降序
```

## 四、数据可视化：ggplot2

`ggplot2`是R中最强大的可视化包——它基于“图层语法”（Grammar of Graphics），把图表拆解为数据、映射、几何对象、统计变换、坐标系、主题等独立组件。

### 4.1 ggplot2核心语法

```R

library(ggplot2)
# 基本结构
ggplot(data = df, aes(x = 城市, y = 销售额)) +
  geom_col() +                       # 柱状图
  labs(title = "各城市销售额对比") +   # 标题
  theme_minimal()                    # 主题样式
```

### 4.2 常见图表类型

```R

# 柱状图（geom_col / geom_bar）
ggplot(df, aes(x = 城市, y = 销售额)) +
  geom_col(fill = "steelblue") +
  labs(title = "各城市销售额") +
  theme_minimal()
# 折线图（geom_line）
ggplot(df, aes(x = 月份, y = 销售额, group = 1)) +
  geom_line(color = "steelblue", size = 1.2) +
  geom_point(size = 3) +
  labs(title = "月度销售趋势") +
  theme_minimal()
# 散点图（geom_point）
ggplot(df, aes(x = 广告费, y = 销售额)) +
  geom_point(size = 3, alpha = 0.6) +
  geom_smooth(method = "lm", se = TRUE) +  # 添加回归线
  labs(title = "广告费与销售额关系") +
  theme_minimal()
# 箱线图（geom_boxplot）
ggplot(df, aes(x = 城市, y = 销售额)) +
  geom_boxplot(fill = "lightblue") +
  labs(title = "各城市销售额分布") +
  theme_minimal()
# 直方图（geom_histogram）
ggplot(df, aes(x = 客单价)) +
  geom_histogram(bins = 30, fill = "steelblue", color = "white") +
  labs(title = "客单价分布") +
  theme_minimal()
# 热力图（使用geom_tile）
# 常用于展示二维交叉汇总数据
df_heatmap <- df %>%
  group_by(城市, 产品) %>%
  summarise(销售额 = sum(销售额))
ggplot(df_heatmap, aes(x = 产品, y = 城市, fill = 销售额)) +
  geom_tile() +
  scale_fill_gradient(low = "white", high = "steelblue") +
  labs(title = "城市×产品销售额热力图") +
  theme_minimal()
```

### 5.1 描述统计

### 5.2 假设检验

#### t检验（比较两组均值）

```R

# 单样本t检验：样本均值是否等于某个值
t.test(df$销售额, mu = 20000)
# 独立样本t检验：两组均值是否有显著差异
# 假设有两组数据：北京和上海的销售额
beijing <- df %>% filter(城市 == "北京") %>% pull(销售额)
shanghai <- df %>% filter(城市 == "上海") %>% pull(销售额)
t.test(beijing, shanghai)
# 配对样本t检验：同一组对象前后两次测量
# t.test(before, after, paired = TRUE)
```

#### 卡方检验（检验分类变量之间的关联）

```R

# 创建列联表
table_data <- table(df$城市, df$产品类别)
table_data
# 卡方检验
chisq.test(table_data)
```

#### 方差分析（ANOVA，比较多组均值）

```R

# 单因素方差分析
aov_result <- aov(销售额 ~ 城市, data = df)
summary(aov_result)
# 事后检验（哪两组有显著差异）
TukeyHSD(aov_result)
```

### 5.3 线性回归

```R

# 简单线性回归：销售额 ~ 广告费
lm_result <- lm(销售额 ~ 广告费, data = df)
summary(lm_result)
# 多元线性回归：销售额 ~ 广告费 + 客户数
lm_result <- lm(销售额 ~ 广告费 + 客户数, data = df)
summary(lm_result)
# 提取回归系数
coef(lm_result)
# 提取R²
summary(lm_result)$r.squared
# 预测
new_data <- data.frame(广告费 = c(30, 40, 50), 客户数 = c(150, 180, 200))
predict(lm_result, new_data)
```

## 七、面试/实战中怎么用

### 7.1 面试高频题

**题目1：R和Python在数据分析中的区别是什么？**

回答要点：R专为统计设计，统计模型更直接、学术社区支持更强；Python通用性更强，适用于生产环境和机器学习。选择取决于场景：学术研究选R，工程部署选Python。

**题目2：dplyr中的管道操作符`%>%`有什么用？**

回答要点：将左侧结果传递给右侧函数作为第一个参数，让多层数据操作从“从内到外”变为“从左到右”，可读性大幅提升。

**题目3：解释`ggplot2`的图层语法。**

回答要点：`ggplot2`将图表拆解为数据（`data`）、美学映射（`aes`）、几何对象（`geom_*`）、统计变换（`stat_*`）、坐标系（`coord_*`）、主题（`theme`）等独立组件，通过`+`叠加组合，使得图表的构建灵活且可复用。

### 7.2 常见统计面试追问

| 追问 | 回答要点 |
|:-----|:---------|
| "p值的含义是什么？" | p值是在原假设成立时，观察到当前或更极端结果的概率。p<0.05表示结果具有统计学显著性 |
| "R²和调整后R²的区别？" | R²随自变量增加而增加，调整后R²对自变量数量进行惩罚，防止过拟合 |
| "t检验和方差分析的区别？" | t检验比较两组均值，方差分析比较两组以上均值的差异 |


## 八、常见误区

| 误区 | 真相 |
|:-----|:-----|
| "R和Python只能选一个" | ❌ 两者可以互补——用Python做数据清洗和自动化，用R做统计分析和可视化 |
| "R的循环和Python一样快" | ❌ R的循环很慢，应尽可能使用向量化操作（如`apply`家族、`dplyr`的向量化函数）|
| "`<-`和`=`在R中完全一样" | ❌ 在R中，`<-`是标准的赋值符号，`=`在某些上下文中也可用，但习惯上推荐使用`<-`，以避免与函数参数传递产生混淆 |
| "`ggplot2`只能画基础图表" | ❌ `ggplot2`的扩展包（如`ggrepel`、`patchwork`、`plotly`等）可以做出非常复杂和精美的图表 |
| "R的统计分析结果可以直接使用，不需要验证假设" | ❌ 使用t检验前需验证正态性和方差齐性，使用回归分析前需检查残差 |
