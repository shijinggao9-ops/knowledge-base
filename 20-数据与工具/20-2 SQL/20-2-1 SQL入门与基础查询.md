# 20-2-1 SQL入门与基础查询（SELECT、WHERE、ORDER BY）

**定位**：SQL是数据领域的“通用语言”——无论你使用MySQL、PostgreSQL、SQL Server还是BigQuery，核心语法都是相通的。这个文件是SQL学习的起点，覆盖从“数据库是什么”到“从一张表中精确取出所需数据”的全过程。掌握这些基础，你就能完成工作中80%的简单取数需求：查客户信息、看订单记录、做基础筛选。更重要的是，这个文件为你建立正确的SQL思维框架——查询是“声明式”的（告诉数据库你要什么），而非“过程式”的（告诉数据库怎么做）。

**适用场景**：从数据库提取业务数据、面试中的SQL入门题、产品/运营/分析岗位的基础取数需求、自助BI工具（如Power BI/Tableau）中的原生查询。


## 一、核心概念词典

### 1.1 什么是SQL？为什么需要它？

**SQL（Structured Query Language，结构化查询语言）** 是一种用于管理和操作关系型数据库的标准化语言。

**为什么需要SQL？**

| 场景 | Excel能处理吗？ | SQL能处理吗？ |
|:-----|:---------------:|:-------------:|
| 数据量 > 10万行 | ❌ 卡顿或崩溃 | ✅ 轻松处理亿级数据 |
| 数据存储在服务器上 | ❌ 需要导出文件 | ✅ 直接在服务器查询 |
| 多张表关联查询 | ❌ 需手动VLOOKUP | ✅ 一条JOIN搞定 |
| 需要定期自动取数 | ❌ 手动重复操作 | ✅ 脚本自动化 |
| 多用户同时访问 | ❌ 容易版本冲突 | ✅ 数据库自带并发控制 |

**核心思维转换**：

| Excel思维 | SQL思维 |
|:----------|:--------|
| 看到的是全量数据 | 看到的是“查询结果”（数据库中的数据是不变的）|
| 操作是“点击+拖拽” | 操作是“写指令” |
| 数据存储在本地文件 | 数据存储在远程服务器 |
| 公式写在单元格里 | 查询写在编辑器里 |


### 1.2 关系型数据库的核心概念

在写SQL之前，先理解数据在数据库中是如何组织的。

| 概念 | 类比Excel | 定义 |
|:-----|:----------|:-----|
| **数据库（Database）** | 整个工作簿 | 多个数据表的集合 |
| **表（Table）** | 一个工作表 | 二维结构，有行有列 |
| **列（Column）** | 一列 | 数据的一个字段（如“姓名”）|
| **行（Row）** | 一行 | 一条完整的数据记录 |
| **字段（Field）** | 单元格 | 某行某列交叉处的值 |
| **主键（Primary Key）** | 唯一ID列 | 唯一标识一条记录的列（如“订单号”）|

**示例**：一张“客户表”可能是这样：

| customer_id（主键）| name | city | signup_date |
|:------------------:|:-----|:-----|:-------------|
| 1001 | 张三 | 北京 | 2025-01-15 |
| 1002 | 李四 | 上海 | 2025-02-20 |

### 1.3 SQL的基本结构（CRUD概览）

SQL的操作分为四大类，但数据分析中最核心、最常用的是`SELECT`查询。

| 操作类型 | 关键字 | 用途 | 数据分析使用频率 |
|:---------|:-------|:-----|:----------------:|
| **查询（Read）** | `SELECT` | 从表中提取数据 | ⭐⭐⭐⭐⭐（几乎全用到）|
| 添加（Create）| `INSERT` | 向表中插入新数据 | ⭐⭐ |
| 修改（Update）| `UPDATE` | 修改表中的数据 | ⭐⭐ |
| 删除（Delete）| `DELETE` | 删除表中的数据 | ⭐ |

> 对于数据分析/产品/运营岗位，只需要精通`SELECT`查询即可，`INSERT/UPDATE/DELETE`了解即可（这些通常由开发或DBA负责）。

### 1.4 第一个查询：SELECT 和 FROM

#### SELECT

用于指定你想查看的列。

```sql
-- 查看所有列
SELECT * FROM 表名;

-- 查看指定列
SELECT 列名1, 列名2 FROM 表名;

-- 给列起别名（AS可以省略）
SELECT 列名1 AS 别名1, 列名2 别名2 FROM 表名;```
```
**示例**：
```SQL-- 查看customers表的所有数据
SELECT * FROM customers;

-- 只查看姓名和城市
SELECT name, city FROM customers;

-- 使用别名，让列名更易读（中文别名需加引号）
SELECT name AS 客户姓名, city AS 所在城市 FROM customers;
