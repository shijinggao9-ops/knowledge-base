## 五、三条核心工作流

### 工作流1：输入 → 整理（Daily Note + Inbox）

```
每天：
  1. 打开 Daily Note（自动引用模板）
  2. 随手记录输入、灵感、问题
  3. 不纠结分类，全部丢进 Inbox

每周日（30分钟整理时间）：
  1. 回顾本周 Inbox 内容
  2. 判断每条笔记属于哪个模块
  3. 创建正式笔记（使用对应模板）
  4. 打上 #S1-初学 标签
  5. 在对应 MOC 中添加链接
  6. 清空 Inbox
```

### 工作流2：主题深耕（MOC 牵引）

```
每月初：
  1. 选定 1-2 个重点模块
  2. 更新该模块的 MOC 页
  3. 列出该模块的「待填补盲区」

每月中：
  1. 按盲区清单学习
  2. 每学完一个概念，创建笔记并链接回 MOC
  3. 尝试用费曼测试验证理解

每月末：
  1. 回顾 MOC，更新掌握程度标签
  2. 把 #S1-初学 升级为 #S2-理解
```

### 工作流3：项目驱动（90-项目与复盘）

```
每个项目结束后（强制）：
  1. 创建复盘笔记（使用项目复盘模板）
  2. 提取可复用的知识/框架
  3. 双向链接回相关知识库笔记
  4. 提炼面试素材（STAR故事）
  5. 打上对应岗位标签

每季度：
  1. 回顾所有项目复盘
  2. 更新 85-岗位图谱 中的能力评估
  3. 调整下季度学习重点
```

## 六、Obsidian 推荐配置

### 6.1 必装社区插件
1. **Templater**：比自带模板更强大，支持变量和脚本
2. **Dataview**：用代码查询笔记，自动生成列表/表格
3. **Tag Wrangler**：批量管理标签
4. **Graph Analysis**：分析笔记间的关联强度
5. **Calendar**：配合 Daily Note 使用
6. **Periodic Notes**：周记、月记模板

### 6.2 可选增强插件
- **Excalidraw**：手绘思维导图和流程图
- **Kanban**：看板管理学习任务
- **Mind Map**：将大纲笔记转为思维导图
- **Advanced Tables**：更好的表格编辑体验

### 6.3 核心设置建议
- **新建笔记位置**：`00-Inbox`
- **附件默认位置**：`99-Archive/Attachments`
- **Daily Note 模板**：`00-Inbox/每日速记模板`
- **自动插入模板**：开启「Templater」自动插入
- **链接自动补全**：开启，使用 `[[` 快速链接

### 6.4 Dataview 实用查询（放入 MOC 页）

**查询某模块下所有笔记：**
```dataview
TABLE file.mtime as "修改时间", tags as "标签"
FROM "20-数据与工具"
SORT file.mtime DESC
```

**查询所有待复习的内容：**
```dataview
TABLE file.mtime as "修改时间"
FROM #输出-待复习
SORT file.mtime DESC
```

**查询某岗位相关的所有项目：**
```dataview
TABLE file.mtime as "时间", type as "类型"
FROM #岗位-咨询 AND "90-项目与复盘"
SORT file.mtime DESC
```
